# 《圣旨模拟器》系统规则

> 本文是**判定层唯一真源**：一切数值、边界、判定口径以本文为准。
> 故事层（一句话、人物、分卷、爽点）见 `02_总纲/`；时间与记忆规则见 `00_世界观/时间线规则.md`；红线见 `00_世界观/禁止事项.md`；人物表现与文风见 `00_世界观/小说特点.md`。
>
> 原则：能被读者算出来的，才叫规则；算不出来的，叫作者开挂。

## 一句话

《圣旨模拟器》不是许愿机。它把玩家的注意力换成"下旨次数"，把一道旨意扔进一群各有算计的活人里，只执行其中能被执行的那部分，再把结果累加成世界线偏移。

## 二、下旨次数 = 当日在线玩家数

### 2.1 计数口径

- **刷新**：每日 00:00 重置。不累计、不透支、不能预支明天的。
- **计入**：当日有过有效操作的账号。
  - 有效操作 = 手写一道旨意 / 批阅一次推演结果并给出选择 / 在剧情讨论区留下带推演过程的发言。
  - 无效 = 挂机、只登录、重复注册、脚本、无内容发言。
- **首日保底**：每次新开局首日额外 +1 次，标注"陛下亲笔"。这是林尘唯一完全不依赖他人的一次机会，也是本书所有开局的"起手牌"。
- **冷却**：写旨本身要时间。现实中一次完整穿越（进、看、写、回）在他这里约 40—90 分钟，古代侧可能过几天到几个月。

### 2.2 为什么这个数字最狠

1. 它把"产品增长"和"活命"焊在一起。少一个玩家，明天就少一刀。
2. 它把读者变成共犯。读者知道那个"1"是他自己时，会本能地替他数：今天几个人？够不够？
3. 它给了所有反派一个最干净的刀口——**不用杀他，只要让玩家走**。一次差评潮、一次封号、一次断服务器，比刀更致命。

### 2.3 增长曲线（与卷次绑定）

| 阶段 | 在线玩家 | 每日下旨 | 对应卷 | 他能做的事 |
|---|---|---|---|---|
| 保底期 | 1—3 | 1—4 | 卷一·节点一 | 一道旨改一个变量，靠 43% 的执行度抠出两个月 |
| 个位期 | 4—30 | 4—30 | 卷一·节点二至七 | 同一死局反复补刀，开始拆人事与符玺 |
| 百级期 | 100—900 | 百次 | 卷一·节点八至卷二 | 能同时改"名分 + 人事"两条链 |
| 千级期 | 1,000—9,000 | 千次 | 卷二后段至卷三前段 | 能把"程序"当武器，救一批人 |
| 万级期 | 1 万—9 万 | 万次 | 卷三至卷四前段 | 能同时开两个死局，有余力"试错" |
| 十万级 | 10 万以上 | 十万次 | 卷四后段至卷五 | 次数不再是瓶颈，**判断**才是 |
| 终局 | — | — | 卷六 | 次数多到没意义，他开始主动不用 |

> 写作提醒：次数一多，紧张感会掉。所以每一次数量级跃迁，必须同时换掉"稀缺物"：从"次数不够"换成"执行度不够"，再换成"偏移不够用"，最后换成"我不敢写"。

### 2.4 反面用法（给对手）

- 邵钧：买断、抄袭、抢商标、挖人、断渠道——把玩家弄走。
- 司命会：不需要弄走玩家，只需要让"下旨"这件事变成组织行为。
- 校正者：在同一死局里抢执行人，让林尘的次数花得没有意义。

## 三、旨意不可撤回

- 提交即执行。没有预览、没有撤销、没有读档、没有"我重写一遍"。
- 唯一补救：再下一道旨覆盖前一道的效果。代价是——多花一次次数，两份旨意一起累加偏移，而且第二道旨要跟第一道留下的既得利益者打架。
- 因此本书的紧张感不来自"打不打得过"，来自"落笔前那三分钟"。

### 3.1 写作纪律

每道旨意落笔前，读者必须已经知道三件事：

1. 这道旨要花掉今天的第几次；
2. 如果它只执行一半，后果是什么；
3. 写错之后，他有没有第二道旨去补。

三条里缺一条，这道旨意就是白写的。

### 3.2 旨意的六种类型

不同类型的执行度上限不同，这是林尘"选写法"的核心技巧。

| 类型 | 例子 | 执行度上限 | 为什么 |
|---|---|---|---|
| 人事 | 换掉谁、提拔谁、把谁调离 | 高（70—90%） | 有明确受益人，利益动因直接 |
| 名分 | 立谁为嗣、给谁一个什么称号 | 中高（60—85%） | 名分能继承，但需要有人背书 |
| 律令 | 定一条罪、改一条罚 | 中（50—75%） | 要靠官僚系统跑，会被"援引"变形 |
| 钱粮 | 拨多少、从哪儿出、给谁 | 中低（40—65%） | 每一环都有人截流 |
| 路线 | 车驾停哪儿、军队走哪条道 | 中（50—70%） | 取决于沿途的人配不配合 |
| 程序 | 诏书怎么用印、谁来副署、几天内必须发出 | 低（25—55%） | 动的是所有人的习惯，最难 |

**整刀合并**：一道旨同时动用程序、人事、名分三类时，执行度按"整刀"结算，可突破单类上限（最高 65%）——因为三类各有受益者，愿意办的人更多。判定时后台须写明"本刀含×类，合并结算"。\n\n**核心技巧**：想让一件事成，不要写"程序"，要写"人事"；写不动人事，就用"名分"包一层，让执行人自己有利可图。

## 四、执行度

### 4.1 判定只看三件事

1. **有没有人愿意执行**——执行人是否存在、够不够得着、敢不敢。
2. **执行人有没有利益动因**——照办对他有什么好处，不照办有什么坏处。
3. **旨意有没有落在既有的名分、律令、人事结构上**——他能不能"援引着办"，而不是"凭一句话办"。

三件事里少一件，执行度直接砍半；少两件，基本空转。

### 4.2 分档表

| 执行度 | 表现 | 读者的感受 |
|---|---|---|
| 0—30% | 空转。文书发了，没人动，或只在纸面上动 | "早说了没用" |
| 30—60% | 打折。核心动作被删掉一半，剩下的是执行人本来就想要的 | "有点意思，但不够" |
| 60—85% | 大体照办，细节走形 | "成了，但代价在别处" |
| 85%+ | 近似照办。危险信号：这道旨意已经不需要林尘了 | "他要被架空了" |

> 85% 不是好事。执行度越高，说明越多的人在这道旨意里找到了自己的利益——他们接下来会替林尘决定这道旨意该长成什么样。

### 4.3 合理化误读：六种走形方式

写得越空，误读越狠。误读的方向永远朝着执行人的利益，不朝着林尘的意图。

1. **改量**——"日步三里"变成"日步一里，且须侍从扶掖"。
2. **改人**——指的是甲，办的是乙，理由冠冕堂皇。
3. **改时**——照办，但拖到没意义的时候才办。
4. **改序**——该先做的后做，让整件事自己烂掉。
5. **加私货**——在旨意上挂一件自己的事，一起办了。
6. **装没看见**——最省力的一种。文书归档，无人提起，二十天后自动失效。

### 4.4 范本：43% 的那道旨

原文七件事，实际结果：

| 旨意原文 | 执行结果 | 执行度贡献 |
|---|---|---|
| 收系徐市一党，案其诈，弃市 | 27 人收系，徐市海上追获，三日后弃市 | 全额 |
| 所献丹石尽焚 | 焚了，但赵高进"安神汤"，称旧方不在丹石之列 | 打折 |
| 车驾止于平原津 | 照办 | 全额 |
| 日步三里 | 御医以天暑改为日步一里，须扶掖 | 打折 |
| 减膏粱、禁酒及丹石 | 部分照办，酒禁被"祭祀需要"绕开 | 打折 |
| 日进粟米粥三升 | 照办 | 全额 |
| 御史录朕起居，三日一上 | 成了，但赵高请"兼录副本"，李斯许之 | 反噬 |

七件事，三件全额，三件打折，一件反噬。3 ÷ 7 ≈ 43%。

**读者能学到的东西**：同一道旨里，越具体的条目执行度越高，越笼统的条目越容易被解释掉。而"反噬"永远来自你为了让事情办成而不得不加的那一句。

### 4.5 执行度的动态变化

执行度不是一次性数字，它会随局势漂移：

- 林尘把执行人换掉 → 重算。
- 执行人发现照办会死 → 执行度归零，而且他会来杀林尘。
- 旨意产生了既得利益者 → 执行度上升，同时这道旨意开始脱离林尘的控制。

## 五、物质与制度基础（可实现性）

### 5.1 能做什么

- 换人：把一个人从位置上拿掉，或放到位置上。
- 给方向：告诉一群有手艺的人"往哪儿使劲"，不告诉他们"怎么做"。
- 动人心：给一个名分、一个说法、一个可以传下去的故事。
- 改名分：立嗣、追封、赐爵、定谥。
- 调钱粮：把资源从一个口袋挪到另一个口袋。
- 改程序：改诏书的用印、副署、传递、归档流程。
- 改路线：车驾、军队、粮道、使节走哪条路。

### 5.2 不能做什么

- 造火炮、炼钢、育种、造水泥、建军工厂——除非工艺、工匠、矿料、钱粮四样齐备，且齐备本身就是几十年的工程量。
- 凭空变出组织（"成立一个锦衣卫"不是一句话，是人、钱、编制、授权）。
- 让不存在的人执行（旨意不能创造一个忠臣）。
- 让整支军队瞬间倒戈。
- 一句"朕知道了"就让人改变立场。

### 5.3 判据（写作时逐条过）

1. 当代有没有这个材料？
2. 有没有会这门手艺的人？多少人？在哪儿？
3. 钱从哪儿出？谁管这笔钱？他为什么要给？
4. 官僚系统里，这件事该走哪道程序？这道程序平时要几天？
5. 谁会因为这件事受损？他能做什么？

五问里有两问答不上，这道旨意就必须被打回，或者写成"失败"。

### 5.4 反例的写法

不要写"他下令造火炮，失败了"。要写：

> 他写了"命将作监试铸火铳三十门"。执行度 12%。将作监把"火铳"理解成"铜炮"，因为铜炮他们做过；三十门变成三门，因为铜不够；三门里有一门炸了，炸死两个匠人。剩下的两门被送进武库，再没人提起。

失败要失败得具体，读者才会信这个世界的物理法则。

## 六、叠加律

### 6.1 规则本体

- 一道旨意只能改一个变量。
- "死亡""亡国"这类结果是多个变量一起推出来的：身体、继承、军权、符玺、粮道、人心、时机、外敌。
- 所以改掉一个变量，结果往往只是**推迟、换场、换一种死法**，不是扭转。偏移度也因此很小。
- 要让结果真正改变，必须在同一个死局里反复穿越、逐层拆解，每一层重新去争执行度。

### 6.2 卷一示范（读者第一次看懂"叠加"）

| 刀次 | 改的变量 | 结果 | 偏移 |
|---|---|---|---|
| 第一刀 | 病因（丹石）+ 车驾停 | 崩于沙丘 → 病笃于沙丘，至九月崩于井陉 | 0.31% |
| 第二刀 | 符玺与人事（谁能在诏书上用印） | 死期再推，沙丘之变的前提被拆掉一半 | 0.38%（含回头 ×1.5） |
| 第三刀 | 遗诏制度 + 蒙毅回銮 + 扶苏名分 | 活过三十七年冬；沙丘之变不成立 | 1% 级 |

三刀之后，秦的国祚不再必然是二世而亡。但每一刀都比上一刀更难：因为第一刀的既得利益者，已经站到了第二刀的对立面。

### 6.3 叠加律的三个副作用

1. **敌人会学习**。第一次他用"查案"包装清洗，第二次赵高就会先一步把案子做成铁案。
2. **盟友会分层**。每一层拆完，都会出现"这一层吃到肉的人"，他们不希望下一层再拆。
3. **偏移不可逆**。拆得越多，现代侧越陌生；到某一刻他会发现，自己已经不认识这个世界了。

### 6.4 什么时候允许"一次改完"

只有一种情况：这个死局的变量少到只有两个，而且两个变量共用同一个执行人。全书最多用两次，且必须付得起代价。

## 七、世界线偏移与校正

### 7.1 数值口径

- 后台实时显示，两位小数。开局 0.00%，警戒线 5.00%。
- 每次改动累加，不改不回退。
- 粗略量级（作者内部用，不写进正文）：

```
偏移增量 ≈ 变量权重 × 影响人口系数 × 靠近结果节点的程度
```

| 改动 | 典型增量 |
|---|---|
| 改一个人的生死（无官职） | 0.01—0.05% |
| 改一个中层的任免 | 0.05—0.15% |
| 改一条律令并落地执行 | 0.1—0.3% |
| 改继承顺序 / 改一场战役结果 | 0.3—1.0% |
| 改一个王朝的存续 | 1.0—3.0% |

**回头钱**：如果落点越过结果节点、再回头去改，本次增量按倍数计——第一次 ×1.5，第二次 ×2，第三次 ×3，封顶 ×5。规则见 `时间线规则.md` 4.1.1。这条规则的作用是防读档：每回去一次，头顶那把刀就往下压一截。

### 7.2 未到 5% 也有痕迹

这一点必须写透，否则 5% 会变成"突然爆炸"的廉价设定。

- **物件错位**：他记得放在左边的东西在右边。
- **记录对不上**：方志里多了一条他没写过的记载，或者少了一条他确定存在的。
- **熟人微变**：某个人的口头禅换了，某个人的职业换了，某个人的孩子没了。
- **关系缺口**：他认识的一对夫妻，现在不认识彼此。

这些是**磨损**，不是校正。当事人不会觉得不对，只有林尘会。而他又记不清原样——这就是恐惧的来源。

### 7.3 校正（5.00%）

- 触发条件：偏移度 ≥ 5.00%。
- 作用范围：被改动因果链上的人与物——不是"全部历史"，是"这一条链"。
- 表现：替换（换成另一个人，履历自洽）或抹除（从来没有存在过）。
- 包括林尘自己。他之所以还能站在这里，是因为他手里有"证据"：实物、档案、合约、公开记录——这些东西把他锚在了这条世界线上。
- 校正不是爆炸，是"某天你发现某人从来没有存在过，而且所有人都觉得理所当然"。

### 7.4 偏移度的三重身份

1. **倒计时**——悬在他头顶的刀。
2. **筹码**——对手可以逼他改（把偏移推高），也可以逼他不敢改（把某个人的存在绑在偏移上）。
3. **货币**——他可以用"我愿意承担 0.2% 的偏移"来跟司命会谈判。

### 7.5 锚定

林尘对抗校正的唯一手段是"锚"：让某个人、某件事在现实里有足够多的人、物、记录同时指向它。

- 实物锚：一件出土的东西。
- 记录锚：一份公开的、可以查证的文书。
- 人锚：一群认识他、需要他的人。

卷五之后，"锚"从技术手段变成政治手段——他要让别人也愿意替他锚。

## 八、后台执行细节

### 8.1 生成内容

任何一道旨意都会自动生成一份考据级记录。字段固定：

- 人物：谁执行、谁反对、谁被牵连、谁在旁看。
- 地点：具体到县、亭、渡口、崖洞。
- 物量：多少斤、多少件、多少车、多少里。
- 材质与工艺：金、铜、漆、竹、绢、封泥。
- 铭文与落款：刻了什么字，谁刻的，什么格式。
- 时间：年、月、日、时辰。
- 折扣点：哪一句被打折，被谁打的，理由是什么。

### 8.2 日志格式（与正文一致，不得随意改）

```
【历史节点：平原津·始皇三十七年六月｜判定：未完成｜世界线偏移：0.31%】
【旨意存档：诛方士，罢丹石，止车驾，日步，简食。】
【执行度：43%。分支：始皇未崩于沙丘。】
```

写作要求：日志永远冷静、简短、不带情绪。它的冷，才衬得出林尘的热。

### 8.3 三重用途

1. **证据库**——世界线被改动过的唯一比对工具。他记不清，日志记得清。
2. **变现原料**——两千年后，这些细节就是"只有他知道的那部分信息"。第三个崖洞、封泥石、金三百斤、玉十一件——四个数字，八万块。
3. **推理素材**——他常常要从日志里反推"那边后来发生了什么"，因为他不完整保留记忆。

### 8.4 写作要求

- 数字、材质、尺寸、落款越具体越值钱，也越容易被现实侧验证。
- 每个"值钱的细节"都必须在古代侧被**当场写下**，不能事后补。
- 同一个细节可以被用两次：一次在古代救人，一次在现代换钱。这是本书最经济的写法。

## 九、离线惯性

### 9.1 规则

- 他离开平行古代后，那个世界继续按他留下的旨意、制度与本人习性运行。
- 所以他每次回去，面对的都不是他离开时的那个世界，而是"他的旨意已经运行了一段时间"之后的世界。

### 9.2 一句话要变成三样东西

| 形态 | 判据 | 例子 |
|---|---|---|
| 律令 | 可以援引，有罚则 | "以欺君论"——后来的官员可以拿它办人 |
| 名分 | 可以继承，可以争 | 扶苏的"嗣君"身份——赵高必须伪造诏书才能动他 |
| 人事 | 有人靠它吃饭 | 守崖洞的两个亭卒——他们真的会去守 |

### 9.3 唯一判据

他不在的时候，还有没有人有动机继续执行。

- 有 → 这件事会自己长大，甚至长出他没想要的样子。
- 没有 → 他一走，这件事当天就死。

### 9.4 叙事价值

离线惯性是本书"寸进"的物理基础：他不需要一直待在那儿，他只需要把东西留下。这也是他后期敢于"少下旨"的底气——卷五之后，他下的旨越来越少，留下的制度越来越重。

## 十、时间与记忆

### 10.1 时间比例

- 穿越期间，现实只过去数秒。
- 古代侧可过数日到数月。
- 回到现代，变化已经发生，而且"早就发生了"——史料、新闻、别人的记忆，全部自洽。

### 10.2 记忆

- 林尘**不完整保留**平行世界的记忆：记得"我下过什么旨"，记不清"那边后来怎样"。
- 他能记住的，是**自己写下的字**和**自己看过的数字**。所以后台日志是他的外置记忆。
- 现代人对被改写的部分无缝接受。只有"对不上号"的错位感，而且他们会自己找理由解释掉。
- 沈砚秋不是靠记忆察觉异常，是靠考据：一条不该存在的记载、一个不该出现的字、一处不该对得上的年代。

### 10.3 悬念机制

本书最稳定的悬念不是"他能不能改"，而是：

> 他改成了什么？他现在站的这个世界，还是他昨天站的那个吗？

## 十一、现代反哺链条

### 11.1 五步

1. 他在古代下一道旨。
2. 留下可考的痕迹：实物、文字、制度、地名、判例。
3. 两千年后，这条痕迹（遗址、传说、方志、佚文、判例）与现代的某个人、某笔钱、某份合约发生关系。
4. 他凭"只有他知道的那部分信息"进场。
5. 赚成合法收入：线索酬金、顾问费、独家授权、股权、判决书。

### 11.2 硬规则

- **系统不发钱，只给机会。**
- 每一笔都要能被读者从头算到尾：古时做了什么 → 留下什么 → 今天谁需要 → 他凭什么拿到 → 合法收入形式。
- 五格里填不满，就不许写成收入。
- 收入必须"合法"：合同、判决、授权、股权、酬金。不许出现"神秘账户打款"。

### 11.3 收入形式与对应古代动作

| 现代收入 | 古代必须留下的东西 |
|---|---|
| 线索酬金 | 一个具体到能现场验证的位置或数字 |
| 顾问费 | 一套只有他懂的制度细节（用印、副署、传递） |
| 独家授权 | 一件可以确权的实物或一批文书的整理权 |
| 股权 | 一条产业路径（工艺、产地、渠道） |
| 判决书 | 一条可以被现代法律认领的权利链 |

### 11.4 反面清单

- 中彩票、股票内幕、匿名转账、亲戚遗产、系统奖励。
- "他随手买了块地，地下有矿"。
- "某个富豪突然欣赏他"。

## 十二、落点机制（隐藏规则）

- 落点不由玩家选择，而由"所写旨意与某个亡魂执念的契合度"决定。
- 卷一首次露出端倪：他选的是秦末子婴，落的却是尚未病危的始皇。子婴的执念是"秦不该亡"，始皇的执念是"朕不该死"，两者在"不甘心"三个字上重合。
- 到卷四才被完全揭开。含义是：他以为自己在选剧本，其实是剧本在选他。
- 写作要求：每次落点偏移都要留一个可回收的细节，不能靠旁白解释。

### 12.1 卷一的三个细节（可回收）

1. 他写的是"朕不甘心"，不是"朕不想死"。
2. 屏幕上跳出的立绘是子婴，落地的却是始皇的车驾。
3. 系统说"宿主已就位"，没说"已代入"。

### 12.2 卷四的揭开方式

不是有人告诉他，而是他自己算出来的：他发现自己每一次落点，都精确地落在"某个人最不甘心的那一天之前"。他以为这是运气，其实是筛选。

## 十三、固定写作流程

### 13.1 每章改史前必须写清六项

| 项 | 要求 |
|---|---|
| 现实目标 | 这一章他在现实里缺什么（钱、人、时间、信誉） |
| 历史落点 | 年、月、地点、在场的人 |
| 可实现因果链 | 旨意 → 执行人 → 物质条件 → 结果，四段都要落地 |
| 执行度预估 | 三要素各打几分，预计百分比 |
| 偏移风险 | 预计涨多少，涨了之后现代侧哪个熟人会变 |
| 直接获益检查 | 有没有"系统直接送钱"，有就重写 |

### 13.2 每章收束后必须更新

人物状态、资产状态、世界线状态、伏笔双向账。

### 13.3 单章四问

本章是否有明确目标、冲突、反转、章末钩子？四项中有两项为否，重写章纲，不要硬写正文。

---

## 十四、作者自检清单（写完一章，逐条打勾）

- [ ] 这道旨意花了今天的第几次？读者知道吗？
- [ ] 执行度是多少？哪一句被打折？谁打的？为什么？
- [ ] 这道旨意落在物质与制度基础上了吗？五问能答几问？
- [ ] 它只改了一个变量吗？结果只是推迟/换场，还是被写成了"扭转"？
- [ ] 偏移涨了多少？现代侧哪个具体的人或物变了？
- [ ] 这一笔钱，读者能从头算到尾吗？
- [ ] 后台日志的格式对不对？数字和材质有没有前文依据？
- [ ] 这一章离场时，他留下了什么"离线还会继续跑"的东西？
- [ ] 章末钩子是不是"更大的问题"，而不是"下一章再说"？

## 细纲（第 1 章）

### 第 1 章：始皇多活了一天

- 核心事件：林默在濒临到期的测试服里下一道被系统判定"不成立"的验丹旨，现实史料中始皇卒日因此偏移一天。
- 字数目标：2000 字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期；第一阶段第1章；承担立主角处境、立金手指第一印象、抛出全书核心谜团的第一半
- 单元ID/位置：L1-01；单元内第1拍（建立期待）
- 目标情绪：前状态——对着退款通知盘算还能撑几天的焦头烂额；后状态——意识到自己手里那道"不成立"的旨真的动了现实的手指发冷。本章推进单元情绪引擎的"缺口维持→首次点火"。
- 主角目标/关键选择：目标：让测试服跑完今晚，留住最后一个还在线的玩家；关键选择：明知共振值不够、系统会判"不成立"，仍然按下执行。
- 章节定位：推进
- 本章结构公式：现实压力（目的：立处境与钱的具体刻度）+ 下旨被判定不成立（目的：立金手指与规则的第一次交手）+ 史料偏移与打印稿对不上（目的：交付情绪峰值与谜团）+ 玩家也看见了（目的：钩住下一章）
- 章首钩子：未完成动作开局 — 光标停在"执行"上时被第三条退款申请打断
- 爽点：显性爽点弱，属"金手指首次显形"的期待型爽点——系统说没成立，现实却按他写的那一天动了一天。
- 本章标价：三把尺子，立在第3-5点之间：账上 32,600 元＝约三个月；欠周野的服务器垫款；系统写着 1,000 活跃玩家才算"微澜"，此刻在线 3 人。
- 闭环状态：走完 获得/使用/见效 三拍（下旨→收束→史料偏移）；扣住"估值"这一拍——他拿到的这一天既不能换钱也不能上线，第2-4章兑付其真实用途与代价。
- 本章禁止提前释放：纸质件为何不被世界线覆盖；系统为何在判定不成立后仍然收束；玩家观测与共振的关系。卷级常任禁忌见卷纲「本卷禁碰的终局底牌」。
- 写手自由区：三个内测玩家的群聊语气与身份差怎么分；太医验丹那一小段古场面用什么视角呈现（隔着屏幕看／面板文字／只有声音）；林默与周野那段对话的具体措辞；他把两个日期来回比对的节奏。
- 契约风险：契约安全。主角亲自点火、收益归属清晰且立刻指向更大谜团；未动用卷纲禁碰的底牌。

#### 内容概括（五段式）

- 起因：服务器包年当晚到期，第三条退款申请弹出，林默必须在天亮前决定测试服还开不开。
- 发展：三个内测玩家在线，但共振值连"微澜"的门槛都够不着；系统对"让太医验丹"给出成本与低概率，判定不成立。
- 转折：他仍然执行；几分钟后面板标出"收束完成"，而史料里始皇的卒日变了一天。
- 高潮：他翻出三个月前打印的《秦始皇本纪》摘录，纸上写的仍是另一个日期。
- 结尾：落在内测群里小满那句话上——"刚才那个太医，是不是真的把丹炉端到殿里去了？"

#### 情节安排（多线）

- 主线推进：从"这游戏还能不能活"推到"这游戏真的能改历史"，核心谜团（系统账目与现实不符）成立。
- 辅线推进：L02 从"垫款未结、周野犹豫"推到"周野答应再顶一次运维，但要一个上线日期"。
- 事件线 / 任务线：退款通知 → 服务器到期 → 垫款对话 → 下旨 → 收束 → 对账。
- 任务卡点：林默要留住最后一个玩家，卡在"共振值不够、系统判不成立"；卡出选择（照样执行）与代价（他自己也不信这游戏了）。
- 感情线 / 关系线：无显性感情线，但关系变化为——周野的支持被"再顶一次"具体量化成有期限的条件。
- 逻辑线：钱不够 → 必须抢在上线前证明卖点 → 用一次不可能成立的干预去演示 → 现实动了 → 他失去"这只是个模拟"这个前提 → 新问题：系统为什么算错。

#### 人物关系和出场顺序

- 出场顺序：退款弹窗（系统消息）→ 林默 → 周野（消息）→ 内测玩家群（老K、阿岚、小满）→ 剧本面板与沙丘戏 → 线上史料 → 打印稿。
- 镜头准入：周野要的是上线日期与还钱预期；老K要的是"爽"、想下更大的旨；阿岚在权衡退游；小满在意"是不是真的发生了"。四个人各争一样，台词不合并、不平均派发。
- 人物关系变化：林默—周野，从"默认支持"变为"有时限的支持"；林默—内测玩家，从"三个数据"变为"三个见证者"。
- 视角/信息差：深度限知，锁死林默此刻感知。林默不知系统真相；读者与他同步；玩家只知道游戏里看到的画面。
- 信息差触发点：点13。读者手里握着"系统判定不成立"这张牌，由小满一句外行提问提醒一次。

#### 结尾设定和钩子

- 结尾设定：收束落到"屏幕上那行不成立、纸上那两个不同的日期、群里新弹出来的一句问话"三样并置；未解决问题是系统为什么算错；下一章推动力来自"有人在游戏之外也看见了"。

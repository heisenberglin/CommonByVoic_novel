# 第001章 朕不甘心

> 状态：**已定稿**，正文见 `05_正文/第001章_朕不甘心.md`。
> 本细纲不是"待写"，而是**样板章**：后文章纲的节拍、密度、信息释放节奏，都以本章为基准。

## 一、本章任务

1. 用最少的设定，让读者看懂三件事：他快死了（生意）、他能穿（系统）、他穿过去干什么（改史换钱）。
2. 立三条规矩：**旨意会被打折**、**执行度是活人的利益**、**改史能变现但要能算**。
3. 章末给两个钩子：一个近的（邵钧），一个远的（校正）。

## 二、改史六项

| 项 | 内容 |
|---|---|
| 现实目标 | 服务器还剩六天；欠款十二万；在线玩家 1 |
| 历史落点 | 始皇三十七年六月，平原津（渡河已过半） |
| 可实现因果链 | 旨意 → 李斯（查案）+ 赵高（传话）→ 秦律"欺君"罪名 + 少府钱账 + 御医脉案 → 徐市弃市、丹石尽焚、车驾止于平原津 |
| 执行度预估 | 执行人：有（李斯、御医、亭卒）；利益动因：李斯有（可压赵高）；名分：有（秦律）。三要素齐备但被逐条打折 → **43%** |
| 偏移风险 | +0.31%；现代侧暂无可确认变化（太小） |
| 直接获益检查 | 无系统送钱。八万来自"崖洞四个数字"，是他自己在古代留下的信息 |

## 三、场景拍（十拍，与 `小说特点.md` 第五节对应）

1. **卡死**（约 600 字）：后台数字 1；三张账单、律师函、续费提醒；两千一百次下载、十四条评论。
2. **触发**（约 350 字）：不点模板，手写"朕不甘心"；弹窗不是他写的代码；点了"否"，字变了。
3. **进入**（约 300 字）：白光、失重；三感——颠、热、药味。
4. **验身**（约 700 字）：不是他的手；数脉搏、舔牙根、白帕蹭牙；算出"不是将死，是毒到一半"；算出"一个多月"这个数字。
5. **定位**（约 300 字）：掀帷问"到何处了"；平原津；知道自己离那车鲍鱼还有一段路。
6. **试人**（约 900 字）：见李斯（他在称这辆车还剩多少分量）；见赵高（笑很软）；派赵高去传话；抓住"脚步停了一瞬"。
7. **交易**（约 700 字）：跟李斯讲"不是不死，是慢慢死"；把私怨做成案子；要"名分"不要"杀谁"；要脉案副本不给中车府令。
8. **落笔**（约 500 字）：手抖，左手压右手腕；七件事一句写完；金色细字浮起。
9. **结果**（约 400 字）：43%；逐条打折；一条反噬（安神汤）。
10. **回现实 + 变现 + 钩子**（约 1400 字）：史料改成"九月崩于井陉"；玩家 1（游客＿8713）；崖洞四个数字 → 八万；邵钧五十万被拒；0.31%；"校正"。

## 四、关键对白（可作后续对白基准）

1. `"到何处了。"` / `"回陛下，平原津。"` —— 命令句 + 省主语，一问一答不解释。
2. `"他去年要了三千，前年要了三千。人在哪儿。"` —— 用数字逼人，不质问动机。
3. `"朕给你一件真事。"` —— 交易前的固定句式：先给东西，再提要求。
4. `"朕不是要你杀谁。朕是要让这件事有个名分。"` —— 本章的题眼。
5. `"找到了我给你五十万。"` / `"找到石头，您先付八万定金。"` —— 老头用钱说话，他用条款回话。

## 七、章末钩子

两个：

- 近钩（商业）：邵钧被拒，不会消失。
- 远钩（命运）：偏移 0.31%，警戒线 5.00%，"校正"是什么意思。

最后一句话收在动作上：`明天，他还得穿回去。`——不给总结，不给金句。

## 八、文风提示

1. 数字必须具体到不体面：十二万、六天、两千一百次、四十遍、四十三、0.31%。
2. 古代段全靠身体感推进：颠、热、药味、铁锈味、膝盖软。
3. 系统提示一律方括号、无形容词；**它越冷，他越慌**。

## 细纲（第 2 章）

### 第 2 章：它认了

- 核心事件：服务器到期关服，林默把剧本搬到离线硬盘本地跑；他用第二次干预做可预测性验证，现实里出现与他写在纸上的预测一项项对得上的文书痕迹。
- 字数目标：2000 字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期；第一阶段第2章；承担把"偶然"升级成"可控"，并偿还第1章"那道旨到底算不算数"这笔期待债
- 单元ID/位置：L1-01；第2拍（验证可控）
- 目标情绪：前状态——手里握着一件真东西却拿不出第二份证据的心虚，连他自己都开始怀疑是不是记错了；后状态——把写满预测的纸和屏幕并排、逐项打勾时手心发热。本章推进单元情绪引擎的"缺口维持→第二次点火"。
- 主角目标/关键选择：目标：拿到一份能由自己复现的第二证据；关键选择：他先写下预测再去下旨，把验证做成可证伪的实验，而不是再碰一次运气。
- 章节定位：推进
- 本章结构公式：关服绝境（目的：把处境钉死）+ 改成离线实验（目的：立方法与人设）+ 先写预测再下旨（目的：把金手指从偶然升级为可控）+ 逐项对上（目的：交付爽点与钩子）
- 章首钩子：倒计时开局 — 零点一过测试服变成静态页，老K在群里连问是不是跑路
- 爽点：兑现型。他先在纸上写清"应该出现什么、应该出现在哪一类资料里"，再下旨；收束后去查，现实里真的出现一条他三年里从没见过的著录，与他写的预测逐项对上。第1章那句"系统说不成立却发生了"，在这一章变成"我能让它按我写的发生"。
- 本章标价：两把尺子。①续费要 4200 元，账上 32600，他不敢全砸进去，只能把一台工作站挂上二手平台；②他读了三年、此前从没有过这一条的那个检索库，现在是尺子——用"他熟悉的东西变了"来标价。
- 闭环状态：走完 使用/见效；扣住 获得与估值——能力确认可控，但一分钱也换不来。估值拍第5章兑付。
- 本章禁止提前释放：纸质件为何不被世界线覆盖；系统为何在判定不成立后仍然收束；玩家观测与共振的关系。卷级常任禁忌见卷纲「本卷禁碰的终局底牌」。
- 写手自由区：老K在群里的骂法与标点；他写预测那张纸的物理形态与涂改；那条著录所在的资料类型和检索路径；他确认命中之后具体做了什么。
- 契约风险：契约安全。

#### 内容概括（五段式）

- 起因：零点过后测试服变成静态页，老K在群里连问是不是跑路，小满问还能不能玩。
- 发展：他把剧本与史料库搬上那块离线硬盘，在工作站本地跑起来；这一次他决定先写下预测，再动手。
- 转折：他下旨让太医把验丹的事录进诊籍，收束完成后去查，翻到一条他三年里从没见过的著录。
- 高潮：他把写满预测的那张纸摊在键盘上，和屏幕并排，逐项打勾，四项全中。
- 结尾：他翻出一张纸，画下那个只有他自己认识的符号，笔帽合上。

#### 情节安排（多线）

- 主线推进：金手指从"偶然"变成"可控"，第1章"算不算数"这个疑问得到部分回答。
- 辅线推进：L02 从"服务器到期停服"推到"卖掉一台工作站换回续费的钱"。
- 事件线 / 任务线：关服 → 离线跑 → 写预测 → 下旨 → 收束 → 检索 → 命中。
- 任务卡点：他要续费，卡在"钱不够、又不敢把全部现金砸进去"；卡出的选择是卖设备，代价是开发余量少了一台机器。
- 感情线 / 关系线：无显性感情线；关系变化为老K从"要说法"变成"你倒是说话"，林默第一次被当成跑路的人。
- 逻辑线：停服 → 必须本地复现 → 设计可证伪实验 → 命中 → 确认可控 → 新问题：可控为什么还是换不来能活下去的东西。

#### 人物关系和出场顺序

- 出场顺序：群消息（老K、小满）→ 林默 → 离线硬盘与工作站 → 剧本面板 → 预测纸 → 检索页 → 著录。
- 镜头准入：老K要的是"你是不是跑路了"；小满要的是"还能不能玩"；林默要的是"这一次由我自己证明"。本章不给阿岚台词位，只用一句比价维持她的存在感。
- 人物关系变化：林默—老K，从被质疑到被追问；林默—周野，本章无正面戏，垫款与上线日期继续挂着。
- 视角/信息差：深度限知，锁死林默。读者与他同步；玩家只知道游戏停了。
- 信息差触发点：点6。小满在群里说"秦始皇是七月丙寅死的"，读者握着"已经不是了"这张牌，被提醒一次。

#### 结尾设定和钩子

- 结尾设定：收束落在"他画完符号、合上笔帽"这个动作上；未解决问题是这个记号能不能跨过一千八百年留下来；下一章推动力来自他必须决定要不要真的刻下去。
- 章尾钩子：行动预告型 — 他把那张画着符号的纸压在键盘下面，明天要把它刻进剧本，期待度：强；与下一章承接方式为：老K的逼宫会先一步到来。

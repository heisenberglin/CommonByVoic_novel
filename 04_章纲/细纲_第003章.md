## 细纲（第 3 章）

### 第 3 章：撑不过这个月

- 核心事件：老K自己下的旨同样生效，他自己查出了第三份证据，当众把"这游戏撑不过这个月"吃回去；林默随后在剧本里的秦砖位置刻下私有符号。
- 字数目标：2000 字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期；第一阶段第3章；承担把质疑者变成同盟，并把全书最重要的外部锚（私有符号）埋下去
- 单元ID/位置：L1-01；第3拍（反击与立锚）
- 目标情绪：前状态——被老K当众判了死刑、却不能说出真相的憋闷；后状态——看着质疑者自己把话咽回去时那种不厚道、但极痛快的松一口气。本章推进单元情绪引擎的"受阻→反制"。
- 主角目标/关键选择：目标：不再由自己出面证明，让质疑的人自己去验；关键选择：他没有告诉老K真相，只把下旨权限和检索路径给他——把"证明"的成本交给质疑者本人。
- 章节定位：高压
- 本章结构公式：老K逼宫（目的：把打脸对象推到台前）+ 只给路径不给答案（目的：立人设与权力关系）+ 老K自己验出结果（目的：交付打脸爽点）+ 刻符号（目的：埋外部证实的锚）
- 章首钩子：悬念对话开局 — 老K要一个说法，今天之内不给就退群
- 爽点：打脸型，而且由对手自己完成。老K在第1章说过"改手感？我要改历史"和"这游戏撑不过这个月"；这一章他自己下的旨生效、他自己查到第三条证据，然后在群里当场把话吃回去。曾退场的阿岚回来问怎么玩，完成升华。爽点层级来自"有分量的人自己改口"，不是路人甲震惊。
- 本章标价：一把主尺子——老K从"我等着看它怎么死"到"我再下一条行不行"的转变速度；阿岚回来这个动作本身是第二把。
- 闭环状态：走完 使用/见效/获得（第一个同盟玩家）；估值仍扣着，第5章兑付。
- 本章禁止提前释放：玩家下的旨为何也生效（本章只呈现现象，不给答案）；系统是否仍显示判定不成立；纸质件为何不被覆盖。卷级常任禁忌见卷纲「本卷禁碰的终局底牌」。
- 写手自由区：老K那条旨的具体内容（要够中二、够浮夸）；他查证的过程怎么呈现；群里三个人的语气差；符号刻在哪一块砖的位置、怎么刻。
- 契约风险：契约安全。打脸由对手自己完成，主角没有越权解释，收益归属清楚。

#### 内容概括（五段式）

- 起因：老K要一个说法，扬言今天之内不给就退群；小满跟着催。
- 发展：林默不解释真相，只把玩家下旨的权限说明和一条检索路径发给他，让他自己下、自己查。
- 转折：老K消失二十分钟，回来后甩出他自己查到的第三条证据。
- 高潮：老K在群里把"这游戏撑不过这个月"当场吃回去，还问能不能再下一条；阿岚回来了。
- 结尾：林默点开剧本，挑了一块砖，把那个符号刻上去，按下执行。

#### 情节安排（多线）

- 主线推进：从"他一个人能改史"推到"玩家也能改史"，共振之谜第一次露出形状。
- 辅线推进：L02 从"卖设备"推到"续费到账、服务器明天重新开"。
- 事件线 / 任务线：逼宫 → 给路径 → 老K下旨 → 收束 → 老K查证 → 态度反转 → 刻符号。
- 任务卡点：老K要的是"你们是不是骗子"，林默卡在"不能说出真相"；卡出的是关系变化（质疑者变同盟）与一条伏笔（玩家观测）。
- 感情线 / 关系线：无显性感情线；关系变化为林默第一次不是一个人扛，但他没有为此说一句软话。
- 逻辑线：逼宫 → 给路径 → 自证 → 反转 → 他意识到玩家也在改史 → 新问题：那共振到底是什么。

#### 人物关系和出场顺序

- 出场顺序：老K（消息）→ 林默 → 小满 → 剧本面板 → 阿岚（回归）→ 秦砖与符号。
- 镜头准入：老K既要真相也要面子；小满要一个能听懂的答案；阿岚要一个留下来的理由；林默要的是不再一个人扛，但他说不出口。
- 人物关系变化：林默—老K，从被质疑变为同盟；林默—阿岚，从流失边缘拉回；林默—小满，从被追问变成被信任。
- 视角/信息差：深度限知，锁死林默。读者与他同步；玩家以为自己只是玩了一个会变的游戏。
- 信息差触发点：点7。老K在群里欢呼，林默手里握着他们都没有的那张牌。

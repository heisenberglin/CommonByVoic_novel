## 细纲（第 5 章）

### 第 5 章：四十七个

- 核心事件：林默借着直播带来的关注把符号设计稿与游戏链接挂出去，后台玩家数从 3 涨到 47，"改史换现实机会"的闭环第一次跑通；当晚一条来自公司的消息找上门。
- 字数目标：2000 字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期；第一阶段第5章；承担交付本单元第一次现实兑现，并把外部注意与成本同时推上台
- 单元ID/位置：L1-01；第5拍（第一次兑现）
- 目标情绪：前状态——被自己人问住、无人可解释的孤立；后状态——盯着后台数字往上跳时心脏发麻的痛快。本章推进单元情绪引擎的"兑现"。
- 主角目标/关键选择：目标：把符号带来的关注换成能让自己活下去的东西；关键选择：他既不承认也不否认，而是把符号的原始设计稿和游戏链接一起挂出去——用一个可以被验证的东西换玩家，而不是用一个谎。
- 章节定位：兑现
- 本章结构公式：应付小满（目的：立住秘密的边界）+ 挂设计稿与链接（目的：人设与现实操作）+ 数字往上跳（目的：交付爽点与卷契约兑现）+ 成本与外部注意（目的：钩住下一单元）
- 章首钩子：悬念对话开局 — 小满在等答案，群里三个人都在等
- 爽点：收获型。后台数字 3、9、18、47 往上跳；老K在评论区把质疑的人一个个怼回去并拉人进群；改史、关注、玩家这条链第一次跑通。他手上第一次有了"可支配的东西"。
- 本章标价：主尺子是 47 与微澜门槛 1000 的差距；第二把是他自己那笔账——47 个人愿意为它花时间，比他账上那 32600 元更像能救命的东西。
- 闭环状态：走完 获得/估值（第一个可支配资源：玩家）；下一拍的债＝成本上升与外部注意，第6章加压。
- 本章禁止提前释放：来消息的公司是谁、背后是谁（只出现一条措辞客气的联系请求）；石碑；共振真相。卷级常任禁忌见卷纲「本卷禁碰的终局底牌」。
- 写手自由区：他怎么应付小满；链接挂在哪里、介绍怎么写；老K拉人的具体话术；那条公司消息的措辞与落款形式。
- 契约风险：契约安全。收益落在机会与玩家上而不是现金，主角亲自操作完成兑现，未动用终局底牌。

#### 内容概括（五段式）

- 起因：小满在群里连着发三条等答案，老K跟着起哄，他必须给出点什么。
- 发展：他既不承认也不否认，翻出三个月前那张符号原始设计稿，把稿子和游戏链接一起挂到直播回放的相关讨论区。
- 转折：后台数字开始动，3、9、18，一路跳到 47。
- 高潮：老K在评论区把质疑的人一个个怼回去，还拉了一批人进群；他看着后台，第一次觉得这个游戏能活。
- 结尾：当天夜里，工作邮箱收到一条消息，来自一家公司，问他这个项目有没有兴趣聊聊。

#### 情节安排（多线）

- 主线推进："改史→现实关注→玩家增长"这条链第一次跑通，主角第一次拿到可支配资源。
- 辅线推进：L02 从"钱刚够"推到"要扩容服务器、成本上升"；L03 证据线在本章第一次出现外部注意的苗头。
- 事件线 / 任务线：等答案 → 挂设计稿与链接 → 数字增长 → 老K怼人拉人 → 成本上账 → 公司消息。
- 任务卡点：他要回答小满，卡在"承认就暴露、否认就撒谎"；卡出的选择是挂出可验证的东西让答案自己成立。
- 感情线 / 关系线：无显性感情线；关系变化为小满从追问者变成第一个愿意替他说话的人。
- 逻辑线：关注进来 → 需要接得住 → 挂链接与稿件 → 玩家增长 → 需要更多服务器 → 成本与外部注意一起上来。

#### 人物关系和出场顺序

- 出场顺序：群消息（小满、老K）→ 林默 → 符号原始设计稿 → 讨论区页面 → 后台数字 → 老K在评论区 → 工作邮箱。
- 镜头准入：小满要一个答案；老K要的是"这游戏火了"的参与感；评论区的人要的是一个能拆穿的破绽；林默要的是把关注留住。本章不给阿岚台词位。
- 人物关系变化：林默—小满，从被追问到被护着；林默—老K，同盟关系落实为具体行动；林默—未知公司，单向接触开始。
- 视角/信息差：深度限知，锁死林默。读者与他同步；评论区的人只知道有个游戏，不知道这个符号的来源。
- 信息差触发点：点5。他在看后台数字，评论区的人在争论符号是不是游戏故意做的营销，读者知道那确实是他刻的，但不是营销。

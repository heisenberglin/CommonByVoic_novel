## 细纲（第 8 章）

### 第 8 章：展柜后面

- 核心事件：林默到展馆与许清禾当面交锋，现场多出一个她没介绍的人（祁衡）；他不自证，反而向展方提出一个合作交换，把这场质疑变成一次资源谈判。
- 字数目标：2000 字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期；第二阶段第2章；承担把对抗性接触转成一次交换，并交付主角的地位升级
- 单元ID/位置：L1-02；第2拍（当面交锋与交换）
- 目标情绪：前状态——进门前把自己当成被审的人；后状态——把话头接过来、变成提条件那一方时的稳。本章推进单元情绪引擎的"受阻→反制"。
- 主角目标/关键选择：目标：不被钉成伪造者，同时把这次关注换成能活下去的资源；关键选择：他不解释符号，提出把游戏的秦代剧本授权给展方做互动环节，用曝光抵掉他的服务器成本。
- 章节定位：高压
- 本章结构公式：见面与她不介绍的人（目的：把祁衡推到台前）+ 她再要一次说法（目的：把压力顶到峰值）+ 他反手提交换（目的：交付本章爽点与人设）+ 祁衡开口（目的：钩住下一章）
- 章首钩子：反差场景 — 展馆后门开着，正在撤展，他跟着一个穿工牌的人穿过没有观众的展厅
- 爽点：中偏强，操作型加迪化型。他全程没解释一个字，只提了三个条件；她带来的准备全部落空，而她把他的沉默读成"早就等着这一天"。
- 本章标价：两把尺子——那块砖的展签上写着 1976 年入库；以及他报出的那个数字：扩容每月 680 元，这是他开口要资源时唯一的底气。
- 闭环状态：走完 使用/见效/获得（把质疑转成一次谈判）；估值拍第9-10章兑付。
- 本章禁止提前释放：符号来源的解释；祁衡的最终结论（本章只让他问一句物证问题）；沈策与资本方。卷级常任禁忌见卷纲「本卷禁碰的终局底牌」。
- 写手自由区：展厅现场的具体样子与撤展细节；许清禾怎么把话说得留余地又不留漏洞；那个不说话的人做了什么动作；林默提条件的顺序与哪句最短。
- 契约风险：契约安全。主角亲自完成交换，收益归他，未动用终局底牌。

#### 内容概括（五段式）

- 起因：他按约定到展馆，从后门进去，展厅正在撤展，展柜已经空了。
- 发展：许清禾把展品档案摊在桌上，再要一次说法；同来的那个人全程没说话，只看。
- 转折：他不接她的问题，提出把游戏的秦代剧本授权给展方做互动环节，条件是曝光与服务器资源。
- 高潮：她愣住的那几秒里，他把三个条件按顺序说完，一条比一条具体；她意识到自己准备的一整套质问没有落点。
- 结尾：那个一直没说话的人开口了，只问了一句：这块砖上的刻痕，能不能让我做一张拓片。

#### 情节安排（多线）

- 主线推进：质疑方第一次成为资源方，主角拿到第一份非现金收益的入口。
- 辅线推进：L02 从"扩容账单"推到"有人可能替他付这笔钱"；L03 从"一次接触"推到"三个人坐到同一张桌前"。
- 事件线 / 任务线：赴约 → 档案对质 → 提交换 → 她犹豫 → 第三个人开口。
- 任务卡点：他要的是资源，卡在"对方只想要说法，而他给不出"；卡出的选择是把说法换成一份她更需要的东西，代价是把游戏绑进一个他不完全可控的展。
- 感情线 / 关系线：无显性感情线；关系变化为两人从对手变成同一件事的两端。
- 逻辑线：她要说法 → 他给不出 → 他改换交易标的 → 她需要互动内容而他有 → 交易成立 → 但物证问题仍在。

#### 人物关系和出场顺序

- 出场顺序：展馆后门 → 工牌 → 空展柜 → 许清禾 → 展品档案 → 那个没被介绍的人 → 林默的三个条件 → 祁衡开口。
- 镜头准入：许清禾要的是把展览的风险拆掉；那个不说话的人要的是看清楚东西；林默要的是活下去的资源。本场三人，台词集中在前两人，第三个人只用动作参与。
- 人物关系变化：林默—许清禾，从互相提防变为互相需要；林默—祁衡，单向被观察。
- 视角/信息差：深度限知，锁死林默。他不知道那个不说话的人是谁；读者也不知道。
- 信息差触发点：点5。他报出 680 这个数字时，读者知道他账上还剩多少，而对面的人只当他是在算一笔生意。

#### 结尾设定和钩子

- 结尾设定：收束落在那个中年人低头继续看照片的动作上；未解决问题是他是谁、他要拓片做什么；下一章推动力来自拓片会给出什么结果。
- 章尾钩子：神秘物品型 — 一句关于拓片的请求，期待度：强；与下一章承接方式为：三天后她发来拓片的照片。

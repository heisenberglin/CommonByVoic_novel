# 第002章 八万到账，六天变半年

五点十七分，手机在桌上震了一下。林尘伸手把它翻过来，屏幕朝上，看见银行的公众号推送压在最上面，一行数字：80,000.00，附言两个字，定金。

同一条，四点五十八分来过一遍，是短信。他把两条并排看了一次，数字一样，附言一样，余额也一样：81,203.56。

他先看时间。五点十七。

再看余额。最后看桌上那封律师函。落款六月九号，签收六月十号，函上写“三日内付清”。

今天第三天。

他把手机拿近，把那条推送点开。付款方：何九鼎。开户行一栏写着山东的一个支行。到账时间四点五十八分十二秒。附言两个字，定金。合同号、用途、发票信息，一样都没有。

手机屏右上角裂了一道，从上边框爬进来两厘米，是上个月摔的。裂缝正好横在余额那串数字上面。

窗外的天灰了。楼下有人支早点棚子，铁皮腿刮水泥地，一声，又一声。风扇转到头，咔一下，又转回来。墙上那块霉斑比上个月大了一圈，形状像一只没长开的手。

桌上摊着四样东西。三张信用卡账单，最低还款额分别是一千二百四、八百六、六百三十。一封律师函。一条服务器续费提醒，红字：6 天后到期。

他把三张账单摞起来，边角对齐，压回桌角。压完又抽出来，把最后一张翻了个面，对着窗外那点灰光看了两遍。

他抽出一张 A4。上个月打废的报价单，正面印着“年度框架合作报价（含税）”，总额三十七万二。他当时算过，这单要是接下来，一年能填上欠款。

背面空着。他从抽屉里摸出一支笔，笔杆上印着便利店的名字，一块五一支，写两行断一次墨。

他在纸角蹭了蹭，墨才下来。

第一行：80000 − 2100 = 77900。

第二行：120000 − 77900 = 42100。

第三行他写了个日子：六月十九号。

第四行他补了个和：1240 + 860 + 630 = 2730。

他把三张卡的到期日也写上：十六号、二十一号、二十八号。三个日子排在六月剩下的十七天里，一个比一个近。

写完，他把笔帽咬在嘴里，看这四行。他算账有个固定顺序：先算能动的钱，再算缺口，最后把日子填在缺口下面，这样一张纸看过去，他要面对的东西就全在上面了。

八万在账上。三笔支出在门口排队：两千一，买六天；十二万，买一张撤诉；两千七百三，买这个月不接催收电话。

两千一已经花了。十二万今天花不起。两千七百三他决定先不花。

他打开微信零钱：4.62 元。够买两杯豆浆，不够买一包烟。

他把 A4 纸翻到正面，报价单上那行小字还在：预付三成，验收后六十天内结清。三个月前他把这份报价发出去，对面回了一句“再看看”。

他在纸的下半截又写两行：

“服务器停：明天 0 次。”

“钱还了：明天还是 0 次。”

写完，他在两行中间画了一道竖线，把两行连起来。线画得歪，末尾拖出去半寸。

他算过四万二千一要他挣多久。上个月他给一家小公司改后台，收了四千二。按这个价，十个月。十个月里服务器还要再续两次。

浏览器还开着，停在服务商的订单页。三个月前他把年付改成月付：年付三千六，摊到每天九块八；月付三百六十八，摊到每天十二块二。改的时候他拿计算器按过，一年他撑不到。

那两行他四点五十九分就想清楚了。想清楚之前他看了一眼余额：1,203.56。想清楚之后是 79,103.56。中间隔了十几秒，他把手从鼠标上拿开，等页面转完那个圈。

那一单是半年付，两千一，付款成功，页面没关。

配置他闭着眼也能背：两核四核，内存 4G，带宽 5M，系统盘 40G。这台机器跑着他两年的东西，跑着他唯一一个玩家。

他往后靠，椅子翘起两条腿，后脑勺抵住墙上那块霉斑。

按月付六次是二千二百零八。半年付两千一，省一百零八。

一百零八是他三天的饭钱。

订单页上，到期时间那一行原来是 2026-06-19。现在写 2026-12-13。

他刷新了一遍。还是 12-13。

刷新第二遍。页面底下多出一行灰字：剩余 183 天。

他盯着 183 看，比刚才看八万那会儿久。

然后他截图。只截了有到期日的那一屏，上面那行余额被他拖到框外。图存进桌面一个文件夹，文件夹叫“凭据”。

截完，他又把订单号抄在那张 A4 纸的右下角，抄了两遍，怕自己看错一位。两遍抄完，对了一遍，一样。

支付成功那张页面他没关，上面三行：订单号、金额二千一百、服务期 2026-06-13 至 2026-12-13。他把这三行念出声，念到“十二”那两个字上停住。

微信里翻到“启元法务·李”。对话框最后一条是三天前，对方发的：请于三日内明确还款安排，否则转诉讼流程。

他打字：钱已到。

三个字。发出去，跟一张图。图只截了八万那一条，余额那行裁掉。

发完他把手机扣在桌上，屏幕朝下。

扣下去两分钟，手机在桌面上嗡了一声。一条语音，六秒。

他点开。

“林先生，我是启元的王锐。邵总让我转一句：合同到期前，我们都在。”

六秒。没有第二句。

他把这条语音又听了一遍。第二遍开了免提，声音在这间十二平米的屋里显得大。听完他长按转文字，转出来一行没有标点的字，和听到的一样。

他把这一行截图，也存进“凭据”。存完他点开文件夹，里面已经有七张图了。

八点差十分，微信又亮。启元法务·李回的不是“收到”。

一张表。表头六个字：还款来源说明。

三栏：付款方、合同编号、款项性质。

底下一行小字：本表须于收到后三个工作日内提交，逾期转法务流程。

他把表存下来，先看“付款方”。何九鼎。三个字，没有公司名。这三个字他今天已经见过三回：转账推送、微信昵称，还有这张表，三处写法一模一样。

“合同编号”那一栏后面空着，空得很整齐。

对话框又跳。

“林先生，第三栏‘款项性质’请按以下口径填写：借款／货款／服务费／其他。”

“如选‘其他’，需附书面说明。”

“合同编号为必填项。”

他回：没有合同。

那头隔了四十秒。

“那这一栏无法通过。”

“通过了会怎样。”

“通过后进入还款确认流程。”

他把手机放在键盘上，屏幕朝上，让那几行字亮着。亮了一会儿，屏幕自己暗下去，他又用手指戳了戳。

他点了“服务费”这三个字，页面往下翻出一格：服务内容。他打了四个字，信息咨询，又删掉。

然后去翻何九鼎的微信。

头像是山的照片，灰的，看不出季节，也看不出是哪座山。朋友圈三个月可见，最新一条发在昨天，一张剪报的翻拍。

他往下翻。七条。五条是山，一条是一块石头的近照，一条是剪报。最早那条发于六年前，配文两个字：还在。

剪报拍得歪，标题是《悬赏五十万，寻秦人藏金处》。正文里那个洞的名字印得清楚：琅琊台东北海崖石室。

老人的微信签名是另外五个字：一甲山第三洞。

他把两张图放大，来回看。一个说琅琊台东北，一个说一甲山。两个名字，一个洞。

他在搜索框里分别敲了这两个名字。一个跳出一条景区介绍，一个跳出三条贴吧回复。都不像地址。

他截了图，也存进“凭据”。

然后他把游戏后台调出来，翻到昨天那条执行细节，拉到最底。

倒数第二行：亭卒二人守封存处，去海十七步。

他把这个数在心里念了三遍，才去拨电话。

他站起来，走到窗边。楼下第一锅油条下了锅，油响。他把窗推开一条缝，热气挤进来，和屋里的闷撞在一起。

六点十分。

响两声就接了。那头有风，还有纸页翻动的声音。

“谁。”

“何先生，我是林尘。合同编号。”

“没有编号。”老人说，“我打钱不打编号。”

“律师那边要填。”

“律师要编号，让他来找我。”

那头空了两秒。风大了一阵，接着是打火机的声音，一下，两下，第三下才着。

“你那个洞，第几个。”

“第三个。”

停了四秒。他数着。

“距海多远。”

“十七步。”

又是一阵风。

“你来看一眼。看完我打尾款。”

“多少。”

“四十二。”

电话挂了。

他把手机从耳边拿下来，屏幕上的通话记录停在最上面，号码是山东的，通话时长五十七秒。

他查归属地。日照。他把这两个字抄在 A4 纸背面，抄在“420000”下面。

然后他在“42100”底下补了一行：420000。两个数并排，差一位。

他切回后台。

【当前在线玩家：1】

【今日可下旨次数：0。】

再往下翻一行，是昨天存的那条。

【历史节点：平原津·始皇三十七年六月｜判定：未完成｜世界线偏移：0.31%】

他点开“执行细节”。七条，一条一条排着。

第四条：安神汤。

【折扣点：安神汤。赵高进，称旧方，不在丹石之列，御医不敢阻。】

【供药者：】

后面空的。空格右边有一个灰色括号，括号里两个字：少府。

他把这两个字念了一遍。少府。管皇帝私库的那个衙门。

丹石烧了，药还在进。

他把“少府”抄在 A4 纸背面。写完看了一会儿，又点了一次“进入”。

【今日可下旨次数：0。】

【下一次刷新：17 小时 43 分。】

十七小时四十三分，就是明天零点。

他又点了一次。还是这行字。

页面底下那行在线列表展开，只有一条：游客＿8713，注册四个月前，在线 0 分钟。他自己那个账号在下面，标着“本机”。

两个账号，一个玩家。

他点开游客＿8713。弹出的小窗只有三行：注册时间、最后登录、设备类型。设备类型那一栏是空的。

最后他把表调回屏幕中间。三栏还是三栏，付款方那一栏能填了，合同编号空着。

光标的方框停在“款项性质”后面。四个选项：借款、货款、服务费、其他。

他点了“其他”。页面弹出一行：请附书面说明。

没有模板。他又抽一张 A4，铺平，把笔帽拔下来咬在嘴里。

第一行：本人向何九鼎提供秦代海崖藏金处线索一条。

第二行：信息来源。

后面空着。笔停在句号上。

他把笔尖按在纸上，按出一小团蓝。

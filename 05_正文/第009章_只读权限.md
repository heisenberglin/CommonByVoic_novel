# 第009章 只读权限

六月十八日，上午九点五十。

启元互动在江城高新区，写字楼十七层。电梯里贴着一张广告，招商银行，年化三点一。

电梯到十层停了一次，进来四个人，都穿工牌，说话很快，其中一个在讲“这个客户的回款周期”。到十五层又停一次，进来两个，没说话。

十七层，门开。走廊铺着灰地毯，靠墙一排绿植，叶子尖有点黄。

启元的前台在大门右边，玻璃后面挂着三块铜牌：年度优秀服务商、年度诚信企业、市互联网协会理事单位。

林尘在前台登记。姓名，身份证号，来访事由，被访人。他写：王锐，还款。

访客卡是蓝色的，挂绳上印着启元的标志。前台让他在一张纸上签字，签完递给他一张门禁卡，说出门要还。

他在门口塑料椅上坐了七分钟。左边一间玻璃房里，一个女孩戴着耳机打电话，一句接一句。

“张总，这个月二十五号之前，您这边能不能先走一笔。”

“不是催您。是我们这边要做报表。”

“好，那我等您消息。”

她把耳机摘下来，喝了一口水，又戴上，拨下一个号。

九点五十八，王锐从走廊那头过来，招手。

会议室在走廊尽头，玻璃隔断，桌上摆着三瓶矿泉水，瓶身上有水珠。

王锐先进来，穿浅蓝衬衫，袖子挽到小臂，手里一个文件夹。

“林先生，坐。”

他把文件夹打开，抽出三页纸，推过来。

“《还款计划书》。你看一下，有问题的现在提。”

林尘没坐，先把三页纸从头到尾看了一遍。

第一页是债务确认：本金九万八，服务费两万二，合计十二万。已付零。落款日期六月十八日。

第二页是还款安排：本协议签订之日支付五万元；余款七万元，分七期，每期一万元，自二〇二六年七月二十日起，每月二十日支付。

第三页是违约条款：逾期一日，按未付金额万分之五计息；连续两期未付，债权人有权宣布全部债务到期，并提起诉讼。

最后一行小字：本协议须经债权人委托律师核验后生效。核验律师：苏晚。

林尘把这三页放在桌上，用手压平。

“五万。”他说。

“五万。”王锐说，“剩下的七期，七个月。你签了，我们不起诉。”

“服务费两万二。”林尘说，“这里面有多少是你们的利润。”

“这个不重要。”

“重要。我要知道我在还什么。”

“本金九万八，是我们真金白银垫出去的。两万二是服务费，含催收、法务、资金占用。”王锐把瓶盖拧回去，“你也可以换个算法：你三个月前买的那批量，一千零八十四个下载，九百多个第二天就卸了。钱花得不值，账是实的。”

“两万二能不能减。”

“不能。”

“期数从七期改成十二期。”

“不能。七期是我们法务批的线。”

“首付提到六万，期数压到六期。”

“首付是你今天能拿出来的钱，不是你能谈的价。”王锐说，“你要真能拿六万，我建议你留着，七月二十日那一期别逾期。”

林尘没再说话。

“有一条我可以给你。”王锐把第三页翻过来，指着最下面，“提前还款，不收违约金。你哪天有钱，一次结清，只还剩余本金。”

“这条写进去。”

“已经在里面了。”

林尘把三页重新看了一遍，从第一行看到最后一行。

“不签呢。”

“不签，六月二十四日全额到期。我们走流程。”王锐把矿泉水拧开，没喝，“流程一走，你那个收款账户会被保全。你自己算。”

林尘算过了。昨天晚上算的，在 A4 纸正面。

账户保全，微信支付和支付宝的商户号一起冻。游戏里没有内购，但服务器托管费、域名、短信通道全绑在那张卡上。卡一冻，第三天服务器就欠费。

服务器一停，明天零次。

“五万我付。”他说，“但我要一张东西。”

“说。”

“你们开的收据上，写‘还款’，不写‘服务费’。”

王锐笑了一下：“这个可以。”

“还有一件。”林尘把第三页推回去，“核验律师这一栏，是你们的人。”

“明衡律所，我们所委托的。”王锐说，“她核两件事：这笔钱是不是你的合法收入，你有没有别的财产没申报。核完，协议生效。”

“核不过呢。”

“核不过，协议不生效，五万退你，我们继续走流程。”

林尘把这句话在心里过了一遍。五万退回来，等于他什么也没买到，还多了一次违约记录。

“行。”

王锐没有立刻把笔递过来。他把文件夹合上，两只手压在文件夹上。

“林先生，还有一件事。第九条。”

“用户数据归属。”

“对。你三个月前签的那份推广合同，第九条写的是用户数据归你，但我们要有核验权。”王锐说，“现在我们要行使这个权利。”

“怎么核。”

“给你开一个只读账号，我们技术上去看一遍。看玩家数据有没有被拿去做别的事，有没有转卖，有没有出境。”

“看多久。”

“一周。”

“看什么。”

“用户表，旨意记录，执行明细，审计日志。”王锐数了四项，“导出不开，系统设置不开。”

林尘没说话。

“林先生，这是合同里写的。”王锐把文件夹推开一点，“你可以不给。不给，这份计划书我签不了。”

会议室外面有人推着车过去，车轮在地砖上响。

“给。”林尘说。

王锐起身出去，两分钟后带进来一个人。三十出头，格子衬衫，双肩包还背在身上，手里一个牛皮纸袋。

“周工，技术的。”王锐说，“这位是林先生。”

周工点头，把纸袋放在桌上，抽出一张纸。纸上是六行字，每行前面一个方框。

一、查看玩家列表。

二、查看旨意记录。

三、查看执行明细。

四、查看审计日志。

五、导出报表。

六、查看系统设置。

周工拿笔，在前四个方框里打了勾，后两个画了一道斜线。

“就这四项。”他说，“只读，不能改，不能删。”

林尘把这张纸拿过来，看了两遍。

“我加一行。”他说。

他从王锐那里借了笔，在纸的空白处写：只读权限，不含导出、不含目录、不含日志原文。

写完推回去。

周工看了，抬头看王锐。王锐看了，拿出手机走出会议室。

玻璃隔断不隔音。林尘听见他在走廊里说话，说了三句，两句是“对”，一句是“行”。

三分钟后他回来。

“法务说可以。”王锐把纸放回桌上，“但有一条，权限清单以这张附件为准。附件上没有的，不算我们违约。”

“附件上有导出吗。”

“没有。”

“那就行。”

林尘在两份计划书上签了字。签到第二份的时候，笔尖在“林尘”两个字的最后一横上停了一下，墨洇开一点。

王锐把其中一份装进文件夹，另一份推给他。

“转账吧。”

林尘打开手机银行，输入五万，收款账户是启元互动的对公账号。点下一步，弹出人脸识别，他把手机举起来，对着自己的脸，屏幕上的框晃了两下，绿了。

【转账成功。余额 29,103.56 元。】

他把手机放回口袋。

“收据。”

王锐从打印机那边拿了一张纸过来，还热。上面写着：今收到林尘还款人民币伍万元整。用途一栏：还款。

林尘把收据对折，塞进钱包夹层。

周工已经在角落里打开笔记本。屏幕上是他的后台登录页。

“账号发你了。”周工说，“readonly_qa_01，密码一次性，登录后自己改。”

林尘的手机响了一声，是一条短信。

“收到了。”他说。

王锐把他送到电梯口，帮他按了下行。

“林先生。”

“嗯。”

“邵总前天问过你的账期。”

林尘的手停在门禁卡上。

“他问这个干什么。”

“不知道。”王锐说，“他跟我们老板吃过一次饭。”

电梯到了。门开，里面没有人。

“我多嘴了。”王锐说。

林尘走进去，按了一楼。门合上之前，王锐还站在外面，手里拿着那个文件夹。

走出写字楼是十一点四十。太阳正毒，路面上的柏油软了，鞋底踩上去有点粘。

他在楼下的便利店买了一瓶水，两块钱，扫的码。

余额 29,101.56。

他在便利店门口站了一会儿，把手机计算器打开。

七月二十日，一万。八月二十日，一万。九月，十月，十一月，各一万。

十二月二十日，第六期，一万。

最后一期在二〇二七年一月二十日。

他的服务器到期日是十二月十三日。续费两千一。

十二月他要付两笔：十三号，两千一；二十号，一万。一万二千一。

他在计算器上把这几个数按了一遍，按完清空，又按了一遍。

他把计算器关掉，水没喝完，扔进了门口的垃圾桶。

下午他回家，把计划书、权限清单、收据三样东西摊在桌上，拍了照，存进“六月十八”文件夹。

文件夹里现在有十九个文件。

晚上十点，他打开自己的代码。

他想看一眼，那四项权限在他系统里到底对应什么。

权限模块是他二〇二四年写的，一百四十行，分两个组。一个组叫 read，一个组叫 admin。

read 组里写着五个权限名：view_players、view_edicts、view_detail、view_audit、export_csv。

export_csv 在 read 组里。

他把这一行看了三遍。

两年前他图省事，把导出归到读组。当时只有一个用户，就是他自己。

判定函数更简单：只要用户属于 read 组，can 就返回真。

周工勾的那四项，每一项都把人放进 read 组。

也就是说，那张纸上没有“导出”两个字。系统认的是组。纸上写什么，系统不看。

他把光标移到那一行上。

删掉，保存，重启服务，五分钟。

他打开微信，找到周工，打了一行字：“你们那四项里，有没有需要导出的。”

打完他看了三遍，删了。

问这句话，等于告诉对方这里有扇门。

他又打一行：“账号权限我这边配好了，有问题随时说。”

这一行也删了。

明天早上改，一样的。今晚他已经很困，眼睛发涩，下午在太阳底下走了二十分钟，后颈晒得发疼。

他把编辑器关掉，没有保存。

睡前他把手机调成静音，扣在桌上。

六月十九日，早上七点十分。

他起床，洗了脸，坐到电脑前，先打开后台的审计日志。

审计日志一晚上多了四条。

第一条：02:47:11，账号 readonly_qa_01，来源 IP 113.57.**.**，操作：查询 log_edict，返回 41 行。

第二条：03:12:40，同账号，同 IP，查询 log_edict，返回 41 行。

第三条：03:40:02，同账号，来源 IP 变成本地移动网络，操作：导出 log_edict，41 行，文件名 edict_20260619.csv。

第四条：04:05:19，同账号，查询 log_edict，带筛选条件，返回 9 行。

林尘把第四条看完，手指还放在鼠标上，没有动。

他把滚动条拉到最上面，从头再看一遍。

四条。一夜之间，四条。

他把鼠标移到第一条上，点开。

查询语句展开：SELECT id, created_at, in_world_at FROM log_edict ORDER BY id。

下面是返回值。

返回：四十一行。

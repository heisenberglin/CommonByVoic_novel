# 第010章 他在别人的报表里

六月十九日，上午八点。

林尘睡了四个小时。屋里有一股蚊香味，昨天点的盘香烧到了底，灰落了一桌。

楼下的早点摊已经收了一半，蒸笼摞在推车上，冒着白汽。他买了一笼小笼，八个，六块，站在摊子边上吃完。

手机上有三条未读。两条是运营商流量提醒，一条是房东发的水表照片。

他把手在裤子上擦了两下，上楼，开门，坐下。

林尘把四条审计记录抄在纸上。

第一条，02:47:11，查询 log_edict，返回 41 行。

第二条，03:12:40，同一条查询，返回 41 行。

第三条，03:40:02，导出 log_edict，41 行，文件名 edict_20260619.csv。

第四条，04:05:19，查询 log_edict，返回 41 行。这一条的语句比前三条长，后面带了一个条件。

他把第四条点开。

SELECT id, created_at, in_world_at FROM log_edict WHERE in_world_at >= '0037-09-01' ORDER BY id。

返回：9 行。

林尘看着那个日期。

公元前二一〇年九月一日。

他把手从鼠标上拿开，又放回去。

对方不是在查玩家。

对方在查九月。

他打开数据库，把 log_edict 这张表导出来，一行一行数。

四十一行。

第一行是主记录，旨意全文，一行。往下七行，是七件事的结果。再往下二十七行，是收系那二十七个人，一人一行，姓名、籍贯、处置。最后六行，是六个折扣点：丹石、日步、酒禁、膏粱、兼录副本、海上追获。

一加七加二十七加六，四十一。

这张表他两年没动过。字段是四列：id、edict_id、created_at、in_world_at。

他点开其中几行。

第一行：收系徐市一党二十七人，系咸阳狱。

第九行：徐市，琅琊人，海上追获，三日后弃市，家产没入少府。

第十八行：舍人某，年二十三，不知情，耐为鬼薪。

第二十六行：家令某，供出崖洞三处，减死一等。

第三十一行：丹石三百二十斤，咸阳西市焚，火三日夜。

第三十六行：日步一里，侍医二人扶掖，自平原津至渡口，凡四百步。

第四十一行：九月十二，井陉亭。辒辌车。崩。

他把最后这行读了四遍。

created_at 是写入时间，服务器时间，精确到秒。

in_world_at 是这条记录在秦朝发生的时间。

他先看 created_at。

四十一行，从 05:21:44 到 05:21:50。

六秒。

再看 in_world_at。

第一行，始皇三十七年六月十七。

最后一行，始皇三十七年九月十二。

他拿计算器算了一下。六月十七到九月十二，八十七天。

八十七天，六秒。

他把两列并排贴在屏幕上，来回看了三遍。

一个正常人看到这张表，会得出两个结论里的一个：要么 created_at 是错的，要么 in_world_at 是假的。

两个结论都对他不利。

他把表打印出来。三页纸，横版，四十一行，字很小。他把三页纸在地板上排开，蹲下去，一行一行对。

六月十七，收系二十七人。六月十九，海上追获徐市。六月二十二，弃市。六月二十五，丹石焚讫。七月初三，改步一里。七月十一，酒禁开。八月初九，兼录副本第一份上。九月十二，崩。

他把手指按在最后一行上。

九月十二。这一行他从来没有写过。

他写的旨，到“车驾止于平原津”就完了。九月十二是结果，是系统自己算出来的。

他把那九行九月以后的记录又看了一遍。

九月一日以后一共九行。前八行是路上的事：过巨鹿，宿某亭，换马三次，侍医进粥一升，车轴断一次，补，再断，再补。第九行是九月十二。

他把这九行的 in_world_at 抄在纸上，一行一行排开，中间的空隙有的是三天，有的是半天。

一份坏掉的时钟，不会把路上的事记得这么细。

他站起来，膝盖响了一声。

上午十点，他试着给这件事找一个解释。

第一个解释：服务器时钟漂移。

他把服务器的运行日志调出来。开机时间六月十三日凌晨三点十七，此后没有重启。系统时钟每天和授时中心对一次，偏差零点零三秒。

八十七天等于七百五十一万六千八百秒。任何漂移都漂不出这个数。

第二个解释：in_world_at 记的是剧本时间。真实时间那一列在 created_at。

这个解释是对的。in_world_at 本来就是游戏里的时间，是他自己设计的字段，用来给玩家看“这道旨发生在哪一年”。

他可以写一份说明，三句话就能讲清。

但说明要附证据。证据是：这张表里所有记录都是同一次生成，生成时间六秒。

六秒生成八十七天的历史。

他写了三段说明，写到第三段，停下了。

第三段要证明的是“这只是一个游戏”。证明的方法是拿出 game_ 开头的表，玩家、剧本、存档。

他打开数据库，看表清单。

game_player，game_script，game_save。

三张表都是空的。

因为他做的是单机原型，玩家数据写在 log 表里，剧本写死在代码里，存档功能到上线都没做完。

他把写好的三段全删了。

他把邵钧那份《日志授权意向书》又调出来。

第四条：甲方有权就标的物委托第三方进行技术鉴定。

六月十六日他读这一条的时候，看的是“技术鉴定”四个字，觉得那是保护。

现在他看的是“第三方”。

六月十六日，意向书发出。六月十八日，只读账号交出。六月十九日凌晨两点四十七分，有人开始查。

三天。

他把 PDF 关掉，把手机翻过来，屏幕朝下。

十一点，他去查那条导出记录的来源 IP。

113.57 开头，归属地江城，电信。这个 IP 和夜里那三条查询是同一个，是启元办公室的出口。

第三条导出不一样。IP 是本地的移动网络，4G，基站定位在高新区。

有人在公司查了三遍，然后换了自己的手机流量，把表导了出去。

他在第三个 IP 后面画了一个圈。

下午三点四十，王锐发来一个 PDF。

《现场核验报告（初稿）》，七页。

王锐在微信里写：林先生，核验报告初稿，你先看一下，有异议三天内提。

林尘把七页看完。

第一页是核验范围。第二页是账号与权限清单，附了一张照片，就是他签字的那张纸。第三页是登录记录，四条。第四页是数据抽样，抽了二十行，遮了人名。第五页是结论，两句话：未发现用户数据被转让、未发现数据出境。

他看第四页看得最久。

二十行，每一行前面两块灰条，遮的是姓名。遮得不算干净。第十八行的灰条短了一截，露出一个“某”字后面的半个字。第二十六行整行没遮，“家令某，供出崖洞三处，减死一等”。

抓二十行抽样，两行没遮干净，这是干活的人手快。

但抽样的人选了这两行。

他往下翻。

第六页是建议，三条，都是“建议补充留存”。

第七页是一张表。

表头写着：存量客户风险分级（2026 年 6 月）。

一共十九行，按客户编号排。第七行是他。

客户名称：尘芥信息咨询工作室（个人）。合同金额：一十二万。已回款：五万。风险等级：三类。

备注一栏写着：日志时间戳与业务时间不一致，建议列入观察。

林尘把这一行看了很久。

他的名字在一张别人的表里，占一行，二十几个字。

那张表上还有十八个人。有做电商的，有做本地生活的，有做小程序的。他往下看，看到第十二行，备注写“法人失联”，第十三行写“涉诉两起”。

他在第七行。

三类。观察。

他把 PDF 翻回第三页，看登录记录那一段。报告上写：账号 readonly_qa_01，权限四项，未开导出。下面一行：本次核验未导出数据。

他盯着“未导出”这三个字。

审计日志里有一条导出，三点四十，四十一段，文件名在。

他把两个页面对了一遍。报告写“未导出”，后台记“已导出”。

他没有立刻关掉 PDF。他把这一页截图，存下来，又给文件重命名：报告第3页。

第七页那张表他也截了。

然后他打开三个月前那份推广合同，翻到第九条。

原文是两句话。第一句：本合同项下产生之用户数据，归乙方所有。第二句：甲方为核验数据使用之目的，有权查阅乙方后台用户数据。

用户数据。

日志不是用户数据。日志是他的运行记录，里面没有一个玩家。

启元查的范围，比第九条写的大。

他可以发一封函，指出来。函一发，对方就要解释。解释不了，核验报告就得作废，计划书不生效，五万退回来。

但函一发，对方也会问一句：那你那个日志里是什么。

他把合同合上，压在键盘下面。

然后他打开云端的备份目录。

后台每天凌晨四点自动快照一次，保留十四天。目录里有十四个文件，最早的一个是六月六日。

他点开六月十三日的那份。

解压，搜索 log_edict。表在，四十一行，created_at 全部是 05:21。in_world_at 从六月十七到九月十二。

他点开六月六日的那份。

那张表是空的。

十四份快照，从空到满，中间只有一次变化，发生在六月十三日凌晨五点二十一分。

改是改不干净的。要改，得把十四份全改一遍，还得改服务器的运行日志、授时记录、审计表本身。

而审计表在启元手里有一份 CSV。

他坐在椅子上，看着屏幕上那十四份快照的列表。

手指停在删除键上，停了一会儿，拿开了。

改了就是伪造。伪造一次，后面全是窟窿。这句话是何九鼎前天说的，说的是另一件事。

他从打印机底下抽出一张白纸，横着画了一条线。

最左边一个点，写：六月十三，05:21，四十一行。

往右第一条竖线：六月十六，23:47，一条差评问出处。

第二条：六月十七，用户表的时间反过来。

第三条：六月十八，只读权限交出去。

第四条：六月十九，02:47，有人查九月。

第五条他空着，没写。

写第五条的时候他停了一下，笔尖悬在纸上。

他把笔放下，把纸钉在墙上，用了一枚图钉。图钉钉在六月十三日那个点的上面。

晚上九点，他给周工发微信。

“权限用完了吗。”

十分钟后回：“看完了。”

“有问题吗。”

没有回复。

九点四十，他又发一条：“报告我看了。第七页那张表，三类是什么意思。”

十点整，周工回：“就是观察。”

“观察什么。”

这次隔了很久。

手机放在桌上，屏幕暗下去，又亮起来。他拿起来看了一次，是银行发的分期广告，十二期，年化七点二。他把手机放回桌上，屏幕朝上。

十点二十六，手机在桌上震了一下。

屏幕上是一行字。

“你这后台的时钟是坏的吧。”

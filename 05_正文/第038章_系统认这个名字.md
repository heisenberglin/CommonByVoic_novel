# 第038章 系统认这个名字

后台有一个页面是他自己写的，没接进游戏。

地址在本地：127.0.0.1:8099/admin/people。密码是他的生日，八位数字。

页面上是一张表，六列：序号、姓名、节点、身份、出现次数、来源。

十一个名字。

赵高，三十六次。李斯，二十九次。阿禾，十一次。蒙毅，七次。徐市，四次。阎乐，三次。杜阳，两次。扶苏，一次。蒙恬，一次。

这些数他闭着眼都能背。三十六条明细里，各提了他一句。他没见过赵高三十六次。明细一条一条排下来像账本，谁在哪个时辰、哪辆车、哪句话边上出现了，都算一次。

最后两行他不认识。一栏写“少府某吏”，一栏写“御者”，出现次数都是零，来源那栏是空的。

两个没有名字的人，两条零。

这两行他都试着补过。少府某吏那一栏最早有一个字，他记得是个单名，后来变成空格，他补不回去。御者那一栏从第一天起就是空的。

来源一栏填的是编号，P 开头，P-01 到 P-11。十一份记录，每一份是一道旨跑完之后自动生成的那一堆明细。

这张表是他去年冬天写的。当时是为了查重。同一个赵高，在一条记录里叫“中车府令”，在另一条里叫“赵公”，后台当成两个人，出现次数拆成两半。他加了一个手动合并的入口，顺手也加了“新增”。

写的时候他只想查重。

他点开阿禾那一行。

后台把阿禾的十一条明细列出来。

第一条：驿路第三程，持起居录副本一卷，出驿亭，时七月。

第三条：驿亭长收其腰牌，报县。

第五条：行李一卷，记事，封泥未干。

第七条：判，失足。

第九条：遗物，鞋一双，麻绳一截，封泥半片。

“封泥半片”这四个字后面有一个括号：来源不明。

后台什么都记，就是不知道那半片封泥是从哪儿来的。他把这一行看了两遍，关掉。

十一条。一个死了十四天的人，还有十一条明细在服务器里跑着。每三十秒，判定会把它们重算一遍。

他把阿禾那一行的“身份”看了一眼：执行。

三趟驿路，三趟都是执行。第三趟没到。

三点二十。窗外有蝉，叫得断断续续。后台左下角那行字还在。

【今日可下旨次数：7。】

七次。他从早上到现在一次没用。

他顺手点开玩家列表。七个 ID：咸阳小吏、游客＿8713，还有五个他没见过的：秦半两、子婴他爹、一串数字、“。”、阿房。

七个人，他一个都不认识。昨天七个人各写了一道旨，他一道都没看。

他先在表格最下面点“新增”。

弹出一个框，四项。

姓名：陈屿。

节点：他填了“现实·2026”。

身份：他选了“开发者”。

来源：他填了“2024 年著作权申请”。

点提交。

页面停了一秒。

【无对应历史节点。】

一行红字，压在表格上头。

他盯着这六个字，先想到的是自己写错了格式。

他点开节点那一栏，想看看正确的写法。

红字下面有一行灰字，字很小：节点须为已归档节点。

他去翻数据库。

建表语句在 schema.sql 里，一百四十行。他找到 people 表。

node_id INTEGER NOT NULL REFERENCES nodes(id)

NOT NULL。

他盯着这一句。他不记得自己写过这个约束。

他写东西有个毛病：表先建出来，跑通，约束以后再补。两年里他补过两次约束，都在 README 里记了一笔。他打开 README 往下翻，两条记录，2024 年 6 月和 2024 年 11 月。

没有 3 月 14 日。

他写代码也从来不写外键。外键一加，测试数据就进不去，他吃过一次亏。

他打开命令行，敲 git log -L，找这一行的来历。

2024 年 3 月 14 日 02:07。

就是加了“犯令者黥为城旦”的那一次提交。

作者那一栏是空的。

他把手从键盘上拿开，靠在椅背上，看天花板上的水渍。

一个他不记得写过的东西，两年前被一个没有名字的人写进了他的代码里，今天挡住了他。

他回到页面，点开节点那一栏的下拉框。

一个选项。

平原津·始皇三十七年六月。

就这一个。

他把鼠标移开，又移回来。

一个 2026 年的人，要挂到公元前 210 年的一道旨上。这个动作是什么意思，他清楚。后台所有的人物都必须长在某个节点上，没有节点，就没有人。

系统里没有“现实”这个节点。

他把下拉框点开，选了那一个。

身份那一栏也是下拉：执行、反对、牵连、旁看。四个，没有第五个。

他选了旁看。

点提交。

页面没有再停。

【记录已存。节点：平原津·始皇三十七年六月｜身份：旁看｜出现次数：0。】

表格变成十二行。

陈屿，第十二行。节点平原津，身份旁看，出现次数 0，来源：空。

他点了一下“出现次数”那一格，光标进去了。

他删掉 0，打了一个 1，按回车。

【该字段由判定生成。不可改。】

1 自己跳回 0。

他点“身份”，想改成“开发”。下拉框里没有“开发”。他手动往上敲了两个字，框子变红。

【身份须为四类之一。】

四个身份：执行、反对、牵连、旁看。

他把这四个身份一个一个往陈屿身上套。执行那一格空着：陈屿没下过旨，也没办过旨。反对那一格空着：他没有拦过任何一件事。牵连那一格空着：他没死，没丢官，没被抄家，也没进任何一份名册。

剩下一个。

一个 2024 年跟他一起写代码的人，在这套分类里只有一个位置。

他关掉页面，打开数据库客户端，跳过页面，直接往表里写。

INSERT INTO people (name, node_id, role, count) VALUES ('陈屿', 1, '旁看', 0);

执行成功。一行受影响。

他刷新页面。十二行。

他把 count 那一格改成 1，再写一条 UPDATE。

执行成功。

他刷新页面。还是 0。

他去翻后台的判定日志。日志每三十秒跑一次，最后一条是三点二十四分零七秒。

【判定：people.count 重算。修正 1 行。】

修正的那一行是陈屿。他把 1 改回 0。

他把判定脚本打开看。脚本两百二十行，开头两行是睡眠，然后是一个大循环，把每张表的计数重新算一遍，写回日志。

他一行一行往下翻，翻到第九十几行，看见一个函数名。

reconcile_people()

他自己写的那个叫 recalc_people()。

两个名字差三个字母，功能一样，写法不一样。他这个脚本他改过四十多遍，每一遍都会顺手把旧函数删干净。现在两个函数都在文件里，一个在第一百二十行，一个在第一百八十行，谁先跑他看不出来。

日志的操作人一栏是空的。

他自己的操作，他刚才那两次 INSERT 和 UPDATE，在日志里也有记录，操作人一栏也是空的。

他翻到最上面，把今天所有的操作记录看了一遍。

一百四十七条。操作人一栏全是空的。

这一栏是他自己写的，默认值填的是 system。他打开代码看，默认值还在。

写进去的时候变成了空。

他退出数据库客户端，回到页面。

十二行。

他把这一页截图，存到三个地方：D 盘、网盘、手机相册。

然后他切到游戏目录。

主菜单底下有一页“制作人员”，三行，是他手写的 HTML。

白底，黑字，字号一律十六，没有排版。页脚有一行灰字：版本 0.9.7。

林尘　策划、程序、文本

空行

空行

第二行、第三行本来就是空的。他当时留了两个位置，想着以后招到人再填。

第一版写完他想过在底下加一句“感谢所有试玩的人”，后来没加。那时候试玩的人只有他自己。

他在第一行下面加了一行。

陈屿　考据、数据

保存。文件的修改时间变成 21:04:07。

他先复制了一份到桌面，改名 staff_备份.txt。复制件里那一行在。修改时间跟源文件一样。

他算了一遍源文件的 MD5，记在纸上。

刷新浏览器。制作人员页还是三行：他、一行空、一行空。

他打开源文件。那一行在。

他再刷新。页面还是没有。

他回到源文件。那一行不在了。修改时间 21:04:41。

他又算了一遍 MD5。

两个值不一样。

他打开桌面那份复制件。

那一行也没有了。复制件的修改时间变成 21:04:39。

他复制出去的东西，被人从复制件里也删了一遍。

三十四秒。这三十四秒里他只做了一件事：刷新浏览器。

他把手从键盘上拿开，放在腿上。

然后他打开手机。

微信，通讯录，第八十九个，那个灰头像。

备注栏里那两个字还在。他点进去，把光标挪到“屿”后面，点保存。

页面上转了一个圈，退回来。

备注栏是空的。

他再打一遍。两个字，一个一个打。

保存。退回来。

空的。

他退出微信，从后台彻底关掉，重新打开。

备注栏还是空的。头像还是灰的，位置还是第八十九个。

他做了五次。

第一次，只打一个“陈”。保存。备注栏显示“陈”。

第二次，删掉，只打一个“屿”。保存。显示“屿”。

第三次，打“陈屿”。保存。空。

第四次，反过来打“屿陈”。保存。空。

第五次，他打了“陈 屿”，中间一个空格。保存。显示“陈 屿”。

他删掉那个空格，再保存。空。

单个字能存。加一个空格能存。两个字挨在一起，存不进去。

他在纸上记了一行：备注栏，单字可存，双字不可存，中间加空格可存。

记完他看了一遍这行字。他自己写的实验记录，看着像一份别人留给他的说明书。

他把手机放在桌上，屏幕朝上，看了一会儿。

后台那行字还在屏幕上。

【记录已存。节点：平原津·始皇三十七年六月｜身份：旁看｜出现次数：0。】

他伸手把屏幕转过来一点，正对着自己。

他拿起手机，点那个灰头像，点“发消息”。

对话框开了。顶上那行灰字还在，输入框却能打字。

他打“陈屿”。光标跳了一下，框里的字没了。

他再打。还是没。

他打一个“陈”。留下了。

他盯着那个“陈”字，没有发出去。

手机响了一声。是一条来电提醒。刚才有一个未接，山东的号，尾号 4471。和上个月打了九次的那个是同一个。

他看了三秒，把提醒划掉了。

他站起来，走到窗口，把窗推开一条缝。蝉声一下子大了。

后台的七次还在。

七次机会，一个下午，他一次都没用。

他回到桌边坐下，把那张写了 MD5 的纸折了一下，压在键盘底下。

然后他把手机拿起来，第三次点开那个备注栏。

他打了一个“陈”字。光标停在后面。

他没有再打第二个字。

# 第073章 他的玩家在挖他的洞

铁皮棚是蓝的，四根角钢支着，顶上压了两块石头。棚里一张折叠桌，桌上铺塑料布，布上搁着一台手持 GPS，屏幕还亮。

林尘把它拿起来。机身发黄，边角磨出白底，背面用记号笔写了一个“周”字。

【卫星：7｜精度：±3 米｜电量：41%】

航点十四个。

他往下翻。T01，T02，T03。T03 后面有一行备注：坑三，深一米二，无。

T04 到 T09 空着。T10 叫“3-17”，T11 叫“3-17-2”，T12 叫“3-17-北”。T13 是“E4”，T14 是“E4-补”。

林尘在“E4”上停住。

棚外，何九鼎蹲在坡边抽烟，烟头一明一暗，风把烟往回吹。

“这几个点谁标的。”林尘问。

“姓周的。”老头没回头，“上午来的。五个人，两台车。”

“他带的什么。”

“一张备案。”何九鼎把烟在鞋底按灭，“县文管所的。三个月前他跟我说，动土要报。现在他自个儿来了。”

“报的是谁。”

“我报的。”老头站起来，拍膝盖上的土，“按你说的，报成民间考据，只做线索，不动土。报上去第九天，他带着备案来了。”

“他挖了几个坑。”

“三个。一米二，全是碎石。”何九鼎朝坡上抬了抬下巴，“他找洞道。我也在找。”

林尘把 GPS 放回桌上，屏幕朝上。

E4 是他后台里的网格号。

琅琊这段海崖，他划了六个格子，A 到 F，一格二百米。第三个崖洞在 E4。这个编号只在两个地方出现：后台的地点库，和从地点库生成的执行细节。

玩家看到的是这样三行：

【地点：琅琊·海崖第三洞（E4），距海岸十七步。】

【物量：金三百斤，玉十一件，漆匣六具。】

【封识：洞口立石，刻年月。】

这三个字段是他自己写的。写的时候他想的是可核验：玩家拿着这三行去查，查到，就信这个游戏。

“他怎么知道是 E4。”他问。

“姓周的不说。”老头把烟盒捏扁，扔进棚外的塑料桶，“他那个跟班的说漏了一句。网上有人画了张图。”

“画图的人来过没有。”

“没来过。”何九鼎说，“照着游戏画的。”

林尘没接话。

“你他妈的一个游戏。”老头看着他，“把我找了十四年的地方，画成一张图，贴在网上，让一帮人拿着手机来量我的山。”

老头说这句话的时候没发火。他把手伸进兜里摸烟盒，摸了个空，又把手抽出来。

“他们明天还来？”

“来。”何九鼎说，“他有备案，我只有承包合同。这山是我包的，山底下的东西不是我的。”

坡上有人在笑。二十出头的一个小子，坐在土堆上，两条腿垂在探坑里，手里拿着手机。屏幕横着，是水墨的颜色。他把手机举高了一点，找信号。

林尘认得那个界面。卷轴、朱砂色的边框、下面一行小字：今日可下旨次数。

他站在棚子底下，看着自己的游戏，在一个陌生人的手里，在他的洞上面转。

那小子抬头，看见他，把手机往腿上一扣。

“你也玩这个？”小子问。

“不玩。”

“这游戏邪门。”小子说，“里面写的山，跟我们脚底下这座，一模一样。周所长说这是巧合。”

“哪个帖子。”

“秦史论坛。有个人画了图，十九个点，每个点都有步数。”小子又笑起来，“我照着图找的，一个都没差。”

林尘往坡上走。

洞口在半人高的坡上，草被踩平了，露出一道半圆的黑。姓周的在洞口前面拉了一条红塑料带，带上用记号笔写了四个字：保护区域。

石头还在老地方，靠崖壁立着，齐膝盖，底下垫着三块小石头。

封泥剩一半。他蹲下去，从侧面看那道缝，什么也看不见。

十九步。何九鼎走了三遍，十九步。

他伸手在石头的平面上摸了一下。凿痕是冷的，指头底下有一层浮土。

林尘回到车边，把笔记本从后备箱拎出来，搁在引擎盖上，手机开热点。

【当前在线玩家：7】

他点开论坛。

帖子标题很长：《我把这游戏里的地名抄了四十一道旨，拼成一张图，你们看看像不像》。

发帖人是栎阳贾人。六天前发的。浏览一千二百四十七，回复八十九。

图是手绘的，拍成照片贴上去。一条海岸线，十九个地名，每个地名旁边标了步数、方位、参照物。第三个洞那一格，画了一个方框，框里写 E4。

底下第一条回复是栎阳贾人自己补的：地名全是从执行细节里抄的，一个字没改。

第二条：“E4 那个框我拿尺子量过，跟卫星图对得上，误差不到二十米。”

第五条：“有没有人一起去。我出车，油钱平摊。”

第十一条：“我叔在县里上班，他说那片山归文管所管，别乱挖。”

第三十条：“图我打印了，A3，贴墙上。”

林尘一条一条往下看。八十九条里，有六条在约人上山，十一条在报自己量出来的偏差，十七条在问“第三个洞到底在哪面坡”。

没有人问过一个更简单的问题：这些地名，一个做游戏的人是怎么知道的。

十九个地名。全是他自己写进后台的。

有的是从秦简的注释里抠出来的，有的是他编的。编的时候他想的是像那么回事：名字要土，要短，要让人一看就信。

他做的是考据。玩家拿它做的是地图。

他往下翻回复。第八十九条是三个小时前：

“图已转到胶南野外群，那边有人去过，说山上有铁皮棚。”

林尘把笔记本合上一半，又打开。

他想过一件事：他能不能下一道旨，把琅琊的亭卒调走，把这片山封了。

能。他在两千两百年前说一句话，那片海崖上会多两个守洞的人。

他改不了一张县里盖的章。

他算了一遍账。高铁来回八百七十四，县城招待所八十一晚，住了四晚，三百二十四。租车一天一百六，油钱两百。何九鼎那边雇两个人，一天三百，挖了六天。

他自己的卡里剩四万一千出头。合同上写着三十天，过了第三十一天，那四十二万跟他就没有关系了。

坡上姓周的在打电话，声音不大，一句一句往外蹦：“坐标我有了，深度没有，你们把仪器送来。”

林尘听着，把这句话在心里拆开。

姓周的有坐标，没有深度。何九鼎有洞口，也没有深度。两边都在找一个坡的下面是什么，谁也挖不进去。

只要姓周的还在这座山上，他就得问一句：这些点位是谁给的。

姓周的问何九鼎，何九鼎会说他不知道。姓周的问到游戏公司，游戏公司的注册人是他。

他打开记事本，写了一行：

一、关功能。

地点字段是他游戏里最费工夫的一块。执行细节本来九行，去掉地点、物量、封识，剩六行。七个玩家里有五个是从那个“判定硬得离谱”的帖子里来的，来了就看这三行。

而且图已经在网上。截图转了三轮，转发三百多次。他关掉字段，图还在，人还在山上。

关功能等于把水龙头拧上，地上那摊水不会回去。

他写了第二行：

二、让人挖。

姓周的挖开，出土物归国家。合同上写着尾款四十二万，条件是三点拍照、人到场、看见漆匣。漆匣进了县里的库房，他一分钱拿不到。

何九鼎十四年，换一张收条。

他写了第三行：

三、埋假坐标。

写完他把笔悬在纸上。

这条能成。地点库是他的，坐标字段是他的，词条是从地点库生成的。他改一个数，玩家看到的就是另一个地方。

姓周的拿到了图，就会照着图去量。他往北量一千七百米，那边有一座山，山上没有洞，也没有他的东西。

代价是他要对自己的玩家说一句假话。这句话不挂在嘴上，写进数据里。

以后每一个打开词条的人，看到的都是他写的那个数。

棚外有脚步。何九鼎掀开塑料帘进来，弯腰看了一眼桌上的 GPS，又看他。

“想出法子没有。”

“在想。”

“我给你一个。”老头在他对面坐下，膝盖响了一声，“你别管。他们挖他们的，我挖我的。挖开我认，挖不开我认。”

“他们挖开了呢。”

“那我就看着。”何九鼎说，“我六十三了，看一场也够本。”

林尘没接。

“还有一件。”老头把指节敲在桌面上，“姓周的要问我，这些点位谁给的。我说我不知道。他要是问到你头上，你他妈自己想好一句话。”

“我有话说。”

“你说什么。”

“我说是看地方志看出来的。”

何九鼎看了他一会儿。

“地方志里没有 E4。”他说，“你那个游戏里有。”

他站起来，掀帘子出去，帘子落下来打在铁皮上，响了一声。

林尘坐了很久。车里的热气从脚底下往上蒸，后背的汗把衬衫粘在座椅上。

坡上那小子又开始笑，笑声隔着铁皮传过来，闷闷的。

林尘把笔记本的屏幕调亮。

后台，词条库，地点。

琅琊·海崖第三洞。

字段：坐标（对外）。

现在是两个数：35.41872，119.63418。这是何九鼎报备时用的那一组，写在纸上，盖了章，改不动了。

光标停在输入框里。

他往上翻了两个页面，找到一个两年前写的函数。注释只有一行：随机 + 权重。

那是他写落点模块时用的。他当时用它给每个剧本随机一个落点，落点落地之后，再由权重筛一遍。

他把它复制过来，在后面加了一个范围：南北二点四公里，东西一点八公里。

回车。

屏幕上出来两个数：35.43402，119.63528。

他看了三秒。这两个数落在他划的范围里，往北，一千七百米，落在北岭那道梁上。

他把它们填进坐标那一栏。

下面还有一栏，备注。

他在这里停了最久。

备注是给玩家看的。他要是空着，明天就会有人在论坛上问：这个数谁改的，凭什么改。

他打了一行字：

据玩家“海曲亭长”实地复核，原坐标偏北一千七百米，已更正。

海曲亭长。七个玩家里那个把拼音 ID 改成中文名的，山东口音，六月份自己上过两趟山，在论坛里说过洞口的位置，被骂了四十多层。

他按下保存。

词条的更新时间跳到 19:41。

他刷新了一遍。

最下面多出一行灰字：本条目于今日 19:41 修订。

他把执行细节重新生成了一次。新出来的三行，第二行换成了北岭的坐标。旧的三行还在历史记录里，他没有删。

页面右下角有一个访问计数。昨天全天十一次。他刷新了三遍，十四。

他打开论坛，用那个两年没发过言的账号，在那张图底下回了一行：

坐标已更正。

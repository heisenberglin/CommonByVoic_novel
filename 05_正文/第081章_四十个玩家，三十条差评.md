# 第081章 四十个玩家，三十条差评

八月四日，上午十点十分。

【当前在线玩家：31。】

三天前是四十。四十，三十八，三十五，三十三，三十一。每天掉两三个，掉得不快，掉得很稳。

他把评论区的统计调出来。

总评论四十七条。一星三十条。二星六条。三星四条。四星两条。五星五条。

他把三十条一星从头看了一遍，拿笔在纸上分堆。

识别不准，十九条。

字太多，七条。

写的旨没用，四条。

纸上三堆，一堆比一堆小。他在这三行数字底下画了一条横线，画完没有往下写。

十九那条里，十四条提到同一句话：字写不出来。

八月十八还有十四天。何九鼎的八月九号还有五天。

桌上摞着三个泡面碗，最底下那个的油已经结了一层白。电费单还贴在门上，六月一百四十七，七月一百六十三，两张都没交。风扇不转了，他把窗户开着，风进来是热的。

他把这三个数写在纸上：十四，五，一百六十三。

他点开最上面一条，附件两张截图。

“我用键盘打了三遍，都识别成别的字。第一遍‘朕命减免天下赋税’出来是‘朕命减负天下赋税’，第二遍出来是‘减兔’，第三遍我放弃了。”

他把这个账号的输入记录调出来。

输入方式：键盘。字数：八。判定：12%。理由一栏四个字：字迹不清。

“减兔天下赋税。”

他在纸上一遍一遍写这六个字，写了两行。

然后他去看第七条。

“判完给我九行字。六行是我不认识的人名，两行是我看不懂的官名。我不是来读古文的。”

他把这一条的判定结果调出来。

九行。第一行“丞相议”，第二行“少府出金”，第三行“郡守移文”，第七行“亭啬夫具报”。

每一行都对应后台一个字段。他写的时候觉得清楚。

第八条。

“我写‘朕命：赐朕黄金万两’，判 0%。我写‘朕命：免天下赋税三年’，判 4%。我写‘朕命：斩赵高’，判 0%。这个游戏到底让不让人玩。”

他把这一条看了两遍。

斩赵高判 0。六月的时候他写过诛方士，43%。赵高不能斩，赵高那时候还在用。

系统比他清楚这一点。

下午一点，他去修那个“减兔”。

先看输入方式的分布。四十个玩家里，三十一个用键盘，九个用鼠标，全是六月到七月注册的老账号。

他的引擎只有一条通道。

不管手写还是键盘，字先进渲染器，变成一张黑白图，再进手写识别，识别出来的字进语义层。

这条通道是二〇二四年八月搭的。那时候只有一个入口，就是鼠标写。

键盘输入是九月加的，加的时候他没有另写一条路，直接把字符串扔进渲染器。

渲染器用的是他自己的字形。他自己的字形是他从六种秦简的摹本里抠的，笔画细，转折硬。

“免”这个字，在他这套字形里，下面那一撇拖得长，收笔处有一点回锋。

“兔”的最后一笔也有。

模型把“免”读成“兔”。

他把这两个字的渲染图并排放在屏幕上，放大到八倍。

两张图，差别在下面那一笔的起笔位置，相差不到两个像素。

他坐在那儿，把两张图看了一分钟。

修法有两条。

第一条，给键盘输入单开一条通道，字符串直接进语义层，不过渲染器。这是半天的活。

第二条，重训识别模型，把印刷体加进训练集。这是三天的活，三千个样本，四十八块显卡钱。

他算了一遍第二条。

三天。三天里，三十一个键盘玩家会掉到二十个以下。一个人一天一次旨，十一个人三天三十三次。三十三次换一个能认字的模型，划得来。

可模型训完，判定的分数还是按老阈值出。他得重标。重标一千四百条，一条要看两遍。

他没有三天。

他把四十八块这个数写在纸上。四十八块买得到一张显卡，买不到三天。

第一条看起来便宜。

他动手写了二十行，写到语义层的接口，停下来。

问题是判定。语义层收到的如果是干净的字，判出来的分数会比现在高。现在十九条差评说的是认不出，改完之后他们认得出，可判定的分数会全变。他的一千四百个手写样本标出来的阈值，是按“识别结果”标的，不是按“原字”标的。

改一条通道，等于把他两年的标定推翻一半。

他把那二十行删了。

删完他靠在椅背上，看天花板那块水渍。水渍比六月大了一圈，边缘发黄。

他给苏晚发了一条：“玩家掉到三十一了。”

过了十分钟，那边回：“八月二十，第二期一万。别动那笔钱。”

“记着。”

“还有。”她说，“韩律师昨天问我，附件三第2条什么时候填。”

“你怎么说。”

“我说八月十八之前。”苏晚回，“他嗯了一声，把抽屉关上了。”

他把手机放下。

第三堆那四条，他一条一条看。

第一条：“我写了一道旨，判 61%，结果出来三行，说我的旨只到了一个乡。我写的是天下。”

第二条：“判完什么也没发生。没有战争，没有死人，没有新皇帝。就是几行字。”

他把这一条抄在纸上的时候，笔尖顿了一下。

这就是他的游戏。一句话扔进一群各有算计的人里，被折成三成、六成、七成八。他花了两年做这个折算。玩家要的是“我说了算”。

他要的东西和玩家要的东西，不在一个地方。

一点五十分，他给何九鼎打了一个电话。

响到第六声接了。

“说。”

“石头的格式我查清楚了。”林尘说，“不是封识。”

那头有电视的声音，一个女声在报天气。声音被调小了。

“接着说。”

“封识要刻年、刻官、刻物数，末字落封，一路刻到底，不留空。那块石头三样全反：没抬头，字和字之间留一指，最后一行下面空着一大片。”

“那是什么。”

“题名。”林尘说，“记人的。谁做的，谁立的，名字刻上去。下面留空，是给后面的人添名字。”

电话那头静了几秒。

“记人的石头。”何九鼎说，“立在洞口。”

“是。”

“记的是谁。”

“认不出。”

“你认不出，省里的人认得出。”老头说，“他们拓了纸拿走。今天上午我看见四个人围着那张拓片看，看到十一点。”

“他们会不会说。”

“不会跟我说。”老头说，“他们跟我的鞋说话。”

林尘把笔在指间转了半圈。

“何先生，您十四年前看见它的时候，石头是不是就在那个位置。”

“就在那个位置。”老头说，“它没动过。底下的三块小石头还是我垫的，垫完我还在最左边那块上画了个叉。”

“画在石头上还是石头上面的土上。”

“石头上。”老头说，“铅笔。我那时候随身带铅笔。”

林尘把这句话记在纸上：铅笔叉，最左边那块垫石。

“这个叉能看出来吗。”

“十四个年头，雨冲了十四回。”老头说，“你要是想靠一个叉证明什么，别想。”

“我不想证明。”林尘说，“我想知道那块石头有没有被人换过。”

那头没有立刻答。

“换过怎么样。”

“换过，那这个洞就还是您的洞。”林尘说，“没换过，那这个洞从一开始就不是藏东西的地方。”

“那我的八万。”

“您的八万我退不了。”

“我知道你退不了。”老头说，“我问的是它买了什么。”

林尘看着桌上那张 A4。四行字，两个来源。

“买了四句话。”他说。

“四句话。”老头重复了一遍，“我十四年，买四句话。”

电话挂了。

下午两点，论坛多了一个帖子。

标题：《这个游戏是一个人做的》。

发帖人是咸阳小吏，注册一百七十四天，写过十一道旨。

正文六行：

“你们骂的那些，我认。识别确实烂，九行字确实难读。但你们想想，一个游戏，秦简的器物名写对了七个，官名写对了十一个，日期按辰记不按日记。这些东西是一个人一条一条核的。核一条要半天。”

底下回复二十三条。前三条在骂他是托。

他把这个帖子看完，点了一下“回复”，光标在框里闪。

他打了一行：“谢谢。”

看了几秒，删了。

又打：“器物名有两条是错的，我还没改。”

也删了。

他把对话框关掉。

三点二十，他刷新评论。

四十七条变五十二条。

第五十二条是今天上午十一点四十发的，ID 叫“薛县仓吏”，头像是默认的灰方块。

“我写的旨判 0%。四个字。你们的判定是不是坏了。”

底下附了一张图。

他把图点开。

一张横格本撕下来的纸，边上留着毛。纸上四个字，用鼠标写的，笔画像蚯蚓，一笔一画，横不平，竖不直。

他先去看这个账号的判定记录。

输入：四个字。判定：0.00。理由：空。

他打开判定引擎的日志，找到那一条。预处理返回 0，模型没有被调用。

他自己开了一个测试窗口。

用鼠标写四个字。判 0.00。

写八个字。判 34%。

写七个字。判 0.00。

写六个字。判 0.00。

写五个字。判 0.00。

写十二个字。判 27%。

他打开代码。

预处理那一层，最前面有一条规则，二〇二五年三月十七号加的。

if len(text) < 8: return 0

他记得那天。有人在评论区刷广告，一串乱码，模型给那串乱码判了 71%。他气得半夜起来，加了这一行，把八个字以下的全拦在外面。

八个字。一行代码。

他盯着这一行看了很久。

然后他把那张图放大。

四个字。

第一个字左边一个月字旁。第二个字，一横，一撇，一竖，一点。第三个字，上面一横，下面一个口，口里一横。第四个字，左边一点，右边一挑，中间一个卧钩，钩里两点。

朕不甘心。

他把图片拖到最大，纸的纤维都看得见。

第四个字那一笔的收尾往上挑了一下，挑出一个很小的钩。

他记得这个钩。六月十三号凌晨，他写到最后那个字，手抖了一下，笔尖在纸上停住，抬起来的时候带出一个小钩。他当时还想，这个字写坏了。

图上那个钩，位置一样，深浅一样，连挑起来的角度都一样。

他把手放在键盘上，没有动。

六月十三号凌晨，这四个字进去，屏幕上跳出来的是【检测到有效旨意】。

他刚才写了四个字，判 0.00。

他调出六月十三号那一条记录，又调出今天这一条，并排放在屏幕上。

一条有弹窗。一条没有。

一条把他送走了。一条连模型都没进。

他把两张图拼在一起，存进那三个地方。

存完他坐在那儿，手还放在键盘上。

那道旨的写法，和他第一道一模一样。

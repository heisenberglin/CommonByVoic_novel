# 第106章 备案

八月二十一日上午九点四十，公证处的车停在巷口。

林尘在楼下等。来的是两个人，一个姓董的女公证员，四十上下，一个助理，背一台便携打印机。打印机装在硬壳箱里，箱子外面贴着一张标签：江城公证处 三号。

“机器在楼上。”林尘说。

“先看环境。”董公证员说，“从进门开始记。”

九点五十二分进门。她先看门牌，看窗外，看桌上那台电脑的型号，把型号抄在本子上。助理在旁边拍照，拍了七张。

“十点整开始。”她说，“从现在起，我说一句，你做一件。做完我记一行。”

“好。”

“先登录。”

林尘登录后台。她把屏幕转过去，对着自己，核了一遍时间。

“系统时间。”

“十点零一分。”

她记下来。

“导出注册表。全量。”

他写查询，跑了两分钟。四百七十一K 的 CSV 落在桌面上。

“打开。从第一行开始，往下翻，翻到最后一页。慢一点，我要拍。”

他翻。四十七页纸在她助理手里过了一遍，一页一页。

翻到第一行的时候她抬手。

“停。”

“这一行没有 IP。”

“没有。”

“没有设备号。”

“没有。”

“为什么。”

“不知道。”

她把笔尖停在纸上，写了一个字：疑。

“这一行我照实写。”她说，“写‘该行 IP 与设备号为空，申请人称不知原因’。”

“写。”

十点四十，打印开始。便携打印机一分钟出三张，声音像撕布。

注册表四十七页，打了十七分钟。执行记录三十一页，打了十一分钟。

打完她让他在每一页右下角签名，签完在骑缝处按手印。印泥是她带来的，一盒，红色。

十一点二十，最后一张表填完。

“数据存在哪儿。”她问。

“云服务器。服务商在内蒙古，乌兰察布。”

“机柜号有没有。”

“没有。租的是云主机，不指定机柜。”

她把这一句写完，抬头。

“我这一份只能公证过程。”她说，“我证明的是：今天上午十点，在这台机器上，从这台机器登录，导出了这些数据，打印了这些页。我不证明这些数据是真的。”

“差在哪儿。”

“差在它们是从哪儿来的。”她说，“你要是能给我一份服务商出具的存储证明，或者把机器搬到机房让我看一眼，我可以再出一份。今天不行。”

“费用。”

“两千八。另加打印，三十八页，一页一块。”

他把钱转过去。她开票，票头写：证据保全。

下楼的时候她说了最后一句。

“你这个表，第一行最麻烦。”她说，“别的都齐，就那一行是空的。对方律师会从那一行开始问。”

“我知道。”

“你知道就好。”她把硬壳箱放进后备箱，“我这份公证书，只能帮你到这里。”

车开走了。

林尘站在巷口，手里抱着三十八页纸加一份公证书。纸很沉，比看上去沉。

下午两点十分，一封 EMS 送到。

信封是牛皮纸的，比昨天那个厚。寄件人一栏印着：江城市文化和旅游局。

林尘上楼，拆开。

里面一份函，四页，附一份举报材料复印件，六页。

函头：江文旅函〔2026〕137 号。

标题：《关于核实网络文化产品内容有关事项的函》。

第一段：我局于二〇二六年八月十九日收到举报，反映你单位运营的网络产品《圣旨模拟器》存在内容问题。经初步审查，现请你单位于收到本函之日起十五个工作日内，提交以下材料。

五项。

一、产品基本情况说明。含运营主体、上线时间、用户规模、收费方式。

二、产品所涉历史内容的依据说明。逐条列明出处，注明版本、页码。

三、具有相关专业背景的专家意见。三人以上，附职称证明与本人签字。

四、用户协议、未成年人保护措施、内容审核机制。

五、举报处理记录及整改情况。

第二段：逾期未提交，我局将依据《网络文化经营单位内容自审管理办法》有关规定处理。

落款：江城市文化和旅游局市场管理处。日期八月二十日。联系电话尾号七七八一。

林尘把四页看完，翻回第二项，又看了一遍。

逐条列明出处，注明版本、页码。

他手上那些细节，有一半能注出处。另一半是他从后台抄下来的，后台的记录，现实里没有对应的书。

他把举报材料翻到第三页。

第三页引了他游戏里一句话，八个字，带引号：署不在前，印不敢下。

引文后面跟一行小字：此语非秦人语。作者为一款网络游戏。

这句话他见过。二〇二六年七月六日，一篇二十三页的论文，注四十一，一字不差。

举报的人读过那篇论文。或者，举报的人是照着那篇论文抄的。

他把这一页折了个角。

三点，律所。

苏晚没有先看那四页。她先把举报材料翻到最后，看举报人署名，再看日期，然后才回头读函。

“十五个工作日。”她说，“九月十一号。”

“第二项答不了。”

“第二项不答。”

林尘抬头。

“不答，就是逾期。”

“不答第二项，答别的。”苏晚把笔放下，“你现在想着怎么证明你没有篡改历史。这条路走不通。你辩解一次，他就让你再解释一条；你解释到第四十条，第五条又出来了。你在跟他比谁知道得多。”

“那怎么办。”

“改你是什么。”她说，“你现在被当成一个游戏。游戏要版号，要报审版本一致，要内容自审。你一样都没有。”

“我不是游戏，是什么。”

苏晚从抽屉里拿出一张表，放在桌上。

“历史推演类教育产品。”

林尘看着那八个字。

“教育产品不归他们管。”

“归。”她说，“在网络上运营，就归。但管的东西不一样。”她用笔在纸上画了一条线，“游戏，管的是‘你有没有按规定报审’。教育产品，管的是‘你的内容有没有依据’。”

“依据我也没有。”

“依据要三个人签字。”苏晚说，“三个人签了，第二项就变成第三项的附件。执法支队不会自己去查秦简，他们看的是有没有人替你背书。”

“背书的人要担责任吗。”

“担。”她说，“签字的人要在意见里写一句‘本人已核对上述内容’。这句话一签，他一辈子都得认。”

“改完这一栏，我那个东西还叫不叫游戏。”

“不叫。”苏晚说，“商店里的分类也要跟着改。现在挂的是游戏，改成教育。改完你在游戏榜上搜不到自己。”

“搜不到会掉多少。”

“一半。”她说，“你现在一百零六个在线，一半是从榜上来的。改了分类，那五十三个明天就不来了。”

林尘把这个数写在纸上。

“还有。”苏晚说，“改完，你不能再写‘游戏’两个字。商店页、宣传语、用户协议，凡是出现的地方都要改。一处没改，举报的人可以再举报一次，理由变成‘申报不实’。”

“改。”

“我让助理列清单。”她说，“一共三十七处。”

林尘把那张表转过来。

表头是《历史推演类教育产品内容说明》，下面十二栏。第六栏是“学科顾问”，三个格子，每格后面写着：姓名、职称、单位、签字日期。

“三个。”他说。

“三个。”苏晚说，“两个我出，一个你出。”

“为什么我出一个。”

“因为我出不了第三个。”她把笔帽扣上，“我能找到两个愿意签字的。第一个，江城大学历史学院退休教授，姓罗，七十三岁，研究秦汉制度，一场讲座五千，签字另算。第二个，省社科院历史所副研究员，姓汤，四十一岁，只肯挂名，不出来说话，三千。”

“这两个能签。”

“能签，签了也没用。”苏晚说，“他们签字，是因为钱和人情。执法支队要是抽一条细节问他们。比如你游戏里那句‘行书日限无夜限’，是从哪本书来的。他们答不上来。”

“那第三个要什么人。”

“要一个答得上来的。”她说，“而且要是那种一问就知道有没有的人。”

林尘把手指按在桌上，一下。

“有一个。”

“说。”

“沈砚秋。”他说，“她写过一篇论文，讲沙丘那一段的后期插入。论文第三节里引了我游戏里的一句话，当反证。”

苏晚抬眼。

“她引了你的东西。”

“引了。注四十一。她在注里写：今人拟秦语，句法犹可至，用字终不可至。”

“她判断你的文本是拟的。”

“是。”

“那她签了字，等于替一个她判过死的文本背书。”苏晚说，“她为什么签。”

“不知道。”

“她认识你吗。”

“不认识。”

苏晚把那支笔在指间转了半圈。

“那就难在这里。”她说，“前两个人签字，我买得到。第三个人，买不到。”

“买不到就不签。”

“不签，第三栏空着，这份说明交上去就是废纸。”她把表推过来，“三个人里少一个，等于零。执法支队看的是人数，不是分量。”

林尘低头看那三个格子。

第一个格子他已经填了：罗，教授，江城大学。

第二个也填了：汤，副研究员，省社科院。

第三个空着，一条横线，横线后面是“签字日期”。

“还有一条路。”苏晚说，“我把这一栏填成‘待补’，先交上去，跟他们谈延期。”

“延期多久。”

“十五个工作日已经是极限。再谈，就是求人。”她说，“求人一次，他们下一次来函就会写得更细。”

窗外的天色暗下来。楼下有人在收摊，铁架子拖在地上，一段一段地响。

“她要是拒绝呢。”

“拒绝，你就换一个人。”苏晚说，“全国做秦简的，副高以上，我数得出十九个。十九个里，能答上你那些细节的，三个。三个里，肯替一个游戏签字的，零。”

“那为什么还写她。”

“因为另外两个不肯。”苏晚把表往前推了一寸，“这张表今天要定。定完我明天一早送过去，还能赶上第一批审核。你今天不填，就等下一批，下一批是十月。”

林尘把表拉到自己面前。

十二栏里他已经填了九栏。剩下的三栏，两栏是日期，一栏是名字。

他拿起笔，笔尖在第三个格子上停了一下。

格子里那一行很窄，够写三个字。

他写了：沈砚秋。

写完他把笔搁下。

苏晚把表抽过去，对着光看了一眼。

“她判过你的东西。”她说，“注四十一那句，是把你的文本判成死的。”

“判过。”

“你确定用她。”

“确定。”

苏晚把表夹进那摞纸，对齐，用桌角的订书机钉了一下。

钉脚压得很平。

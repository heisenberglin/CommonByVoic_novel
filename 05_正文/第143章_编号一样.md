# 第143章 编号一样

九月二十日，上午十点零六分。江城老城区，梧桐巷口。

林尘在打印店门口站了半分钟。卷帘门拉到一半，里头一台机器在响，咔，停，咔。

他弯腰进去。门框上挂一块塑料牌，四个红字：复印打印。

“打东西？”老板从柜台后抬头。四十来岁，蓝T恤洗到发白，肚子把下摆撑开。

“二十四页。两份。”

“五毛一张。双面八毛。”

“单面。”

老板把U盘插进去。屏幕闪了两下，跳出一个文件名。

《汉代诏令的三种程式_1998_扫描》

“这个字念什么。”他用指节敲了敲屏幕。

“诏。”

“哪个诏。”

“言字旁，一个召。”

“哦。”他按了打印，“论文吧。”

“嗯。”

“看着像学生的。”他把纸盒往里推了一格，“前天也有个学生来打，八十多页，开题报告。拿走的时候少一页，回来又打一遍，非要我退他那五毛。我退了。”

机器开始吐纸。第一张出来，纸边是热的。林尘接住，翻过来看背面。

影印件的纸面发灰。右下角一枚方印，印色洇开，只看得清中间一个“藏”字。左边一道黑边，是扫描仪压出来的。

“这书老。”老板说，“九八年的？”

“九八年。”

“九八年我在厂里。”他把出纸口的纸拢齐，“那时候纸好，你看这个白。”

林尘没接话。

二十四张出来，摞成两叠。老板拿一张废纸包了，胶带绕两圈。

“十二块。”

他扫码。到账提示响了一声，很短。

出门时太阳爬到楼顶上面。梧桐叶落了两片在纸袋上，他抖掉。

巷口有人在收废纸。三轮车上一杆秤，秤砣挂在钩上晃。车上压着一摞旧书，最上面那本封面朝下，书脊印着“参考资料”四个字。

林尘从车边过去。收废纸的老头正把一捆书往车斗里塞，塞不进，用脚踩了一下。纸页翻开的声音很脆。

楼道里还是坏的那一盏灯，隔一层黑一格。林尘数着台阶上到五楼，三十九级，二楼半踩空一格，扶了一下墙。

屋里一股闷了一夜的热气。风扇转到最慢那一档，风是温的。林尘把桌上两只碗端进水池，冲两遍，扣在架子上。

纸袋撕开，二十四张摊开。一份原样，一份他打算用铅笔在边角标。

第一页是刊头。《秦汉制度研究》，一九九八年第三期，第四十一页。

作者：沈允之。单位：江城大学历史系。

标题：《汉代诏令的三种程式》。

页脚一行小字：收稿日期，一九九七年十一月四日。

他翻到第二节。木牍形制，讲长度、厚度、刳边、墨书，附一张线图，三枚木牍并排。

第三节是释文。一枚木牍，编号丙七，五行，三十七字。断句是作者加的，原文没有标点，字与字之间留一指宽。

释文印成这样：

凡密诏下，须国舅与宗室各一人同验。

验毕各留副封，一藏其家，一送宗正。

三日不覆，□□□□。

丙七号木牍，许都出土，残。

林尘把最后一行看了三遍。

四个方框。方框下面一句：末四字为墨所蚀，不可辨。

三十七字，剩三十三个。

他把铅笔拿起来，在方框上点了一下，又放下。

四个字。能是什么。

第三节的注里讲出土。注十四，三行，比正文还长。

一九五六年冬，许都城南八里，一个村子打井。打到一丈二尺，出水，也出木头。三枚木牍，一枚裂了，两枚整。打井的人拿回家，当柴禾堆在灶边，堆了半个月。

后来卖给供销社的收购站。收购站收废木，一斤四分。三枚木牍一斤三两，给了六分钱。

注十四写到这里，作者加了一个括号：（此据一九五七年三月县文化馆调查记录。）

再往下两行：一九五七年四月，县文化馆一干部于收购站废料堆见墨迹，以三元赎回。同年十一月，送省。

林尘把这一段读了两遍。

六分钱卖出，三元赎回。中间隔一个月。三枚木牍，一枚在废料堆里裂成两半，丢了。

他算了一下：六分和三元之间，差五十倍。而丢的那一枚，连六分都不值。

下午两点，林尘坐公交去图书城。四站路，两块。

三楼最里面是旧刊摊。两排铁架，架上码着合订本，书脊用麻绳捆。摊主姓吴，六十上下，镜片很厚，左眼那片有一道划痕。

“《秦汉制度研究》九八年第三期。”林尘说。

老吴看了他一眼，弯腰从最底下一层抽出三本，一本一本翻。

“九八年半年一卷。”他翻到第三本，“有。”

“多少。”

“一百二。”

“孔网上八十。”

“孔网上那本没这一页。”老吴把书翻开，翻到第四十七页，“你自己看。”

那一页下角一块黄斑，水浸过，边缘发脆。

林尘把书接过来。

“这本哪来的。”

“下面县馆剔出来的。”老吴说，“一共三本，另外两本上个月让人拿走了。”

“一个人。”

“一个人，现钱，一百八一本。”

“留电话没有。”

“没留。”老吴把眼镜往上推了推，“他要发票，我说没有。他就走了。”

“长什么样。”

“四十来岁，戴帽子。”老吴想了想，“进门先看架子最底层，不看上面。熟客才这么看。”

林尘付了一百二。老吴用报纸包了，两头一折，用一截麻绳捆上。

回屋四点十分。

林尘把合订本翻到末页。注十七印在那里，五行，装订线不压字。

前两行他上午在打印件上读过。第三行是新的。

“编号丙七，一九五七年入藏时所编，非原牍自记。存三十七字，末四字为墨所蚀。”

第五行：“承蒙周君示以照片，谨志。”

一九五七年。

林尘坐了一会儿，把笔记本打开，登进代码仓库。

提交记录一条一条往下滚。他拉到二月。

二月二十六日，凌晨一点十四分。提交说明四个字：加木牍弹窗。

点开。四十七行处：

const tabletId = "丙七"; // 随手编的，别当真

“随手编的”四个字是他自己敲的。

那天凌晨他在给汉线剧本做木牍弹窗，要一串编号。他想了几秒，敲了丙七。丙是天干第三位。七是那天写的第七个弹窗。

他把这行选中，又取消选中。

他建了一个本地副本，把丙七改成乙三，存盘，打开。弹窗里那一行跟着变成乙三。

改回来，打开，还是丙七。

字符串是死的。它不会自己长回来，也不会自己变。

他打开游戏，进汉线剧本第七场。屏幕上浮出一块木牍，字竖排，边上贴一道裂纹的图。

三日不覆，□□□□。

四个方框，是他二月二十六号敲的。他当时懒得编四个字，在键盘上按了四个符号。

林尘把光标停在那四个方框上，停了很久。游戏里的木牍只有这四个方框。

三个丙七。

一九五七年，省文物研究所入藏，编丙七。

二〇二六年二月二十六日，他敲进代码，丙七。

建安四年四月，尚书台第三格柜，第七号，丙七。

他想起尚书台那个管柜的人说的两个字。当时他以为自己听错了，让他重说一遍。

那个人又说了一遍：丙七。

林尘在纸上写这三个丙七，排成三行，中间画两道横线。写完在底下算。

尚书台的编号是三天干配九格：甲、乙、丙，一至九。二十七种。

他随手敲的那一串，落在这二十七种里的一种。二十七分之一。

一九五七年那份库房编号，也落在二十七种里的一种。再乘一次。

七百二十九分之一。

他把笔搁下，看了很久。算错了也不一定，但他没有第二种算法。

手机在桌角震。

“结清证明拿到了。”苏晚说。

“几行。”

“四行。第三行是‘委托人保留就其他事项另行主张的权利’。”

“其他事项。”

“没写是什么事项。”苏晚说，“韩律师加句子不加主语，这是他的习惯。”

“六万他收了。”

“九月二号收的，比期限早一天。”她说，“证明是当天出的。当天出，说明早就写好了。”

“他还留着一条尾巴。”

“尾巴是四个字。”苏晚说，“关联事项包括什么，由他认定。”

林尘把手机换到另一只手。

“我这个月案源少了两个。”苏晚说。

“哪两个。”

“一个是启元介绍来的，一个是他的客户。”她说，“他没说理由，把我的名字从代理栏划掉了。纸上留了一道印子。”

“你现在在哪儿办公。”

“十七楼。靠打印机。”她说，“一天响两百多次。”

“打印机离你几步。”

“三步。”苏晚说，“我数过。”

“论文拿到了。”他说。

“有你要的东西？”

“有。”

“多少钱。”

“一百二。”

“一百二买一句话。”苏晚说，“值不值，看你拿它干什么。”

“我这几天的电话可能打不通。”林尘说。

那头停了一下。

“几天。”

“不知道。”

“上次你说不知道，去了十一天。”苏晚说，“十一天里，平台来函一封，启元的人来了两次，何九鼎的财务打了六个电话。这些我都答了。”

“怎么答的。”

“我说负责人不在。”她说，“他们问在哪儿。我说不知道。”

“他们信？”

“他们不信。”苏晚说，“不信也拿我没办法。我不说谎。我真的不知道。”

林尘没有说话。

“出去之前，把该签的签了。”她说，“我不替你签字。签字的人要能站在法庭上。”

电话断了。林尘给何九鼎拨了一个。

响到第九声才接。那头有风声，老人在外头。

“第三个核验点，九月二十五。”何九鼎说。

“那天我不在。”

“你不在，谁在。”

“苏晚在。”

电话那头空了三秒。

“行。”何九鼎说，“我把日子告诉她。”

“二十二万九月二十五到？”

“到账要五天。十月一号之前。”老人顿了一下，“你又跑？”

“跑。”

“跑几天。”

“不知道。”

“跑之前把字签了。”何九鼎说，“别让人替你在纸上画。”

电话断了。

林尘把手机扣在桌上，屏幕朝下。

他退出通话，打开游戏后台。

【世界线偏移：0.94%｜在线玩家：900】

【今日可下旨次数：900。】

九百次。

他把写三个丙七的那张纸折了两折，放进抽屉。

抽屉里有一个牛皮纸信封，装的是孙守业那份复印件，两页，边角起毛。他把纸压在信封上面，推上抽屉。

他把合订本翻回第四十七页。他在打印件的目录上对了一遍：一、引言。二、许都出土木牍的形制。三、丙七号木牍释文。四、……

目录上第四节的字比前三节粗半号。

七个字：《论密诏同验之制》。

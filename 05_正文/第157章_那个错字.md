# 第157章 那个错字

【历史节点：许都·建安四年六月十七｜判定：未完成｜世界线偏移：1.02%】

【今日可下旨次数：1064。今日已用：10。】

【执行度：44%。第二验缺。补验须宗正。】

六月十七，巳时，林尘睁眼。

他先尝到嘴里的苦。药留在舌根，一夜没有散。背上的席是湿的，湿了一片，形状跟他后背一样。

他坐起来，花了三口气。第一口气撑到肘，第二口气撑到膝，第三口气才站稳。

“郑安。”

“唯。”

“什么时辰。”

“巳时二刻。陛下睡了九个时辰。”

“有人进来过。”

“有。”郑安说，“半夜换了两个医官。原先那两个，一个是卯时走的，一个是辰时走的。新来的两个，一个是相府荐的，一个是太医院自己补的。”

“相府荐的那个姓什么。”

“姓王。三十来岁，手上没有药味。”

“他怎么按的。”

“三指。按了左边换右边，换了三次。”郑安说，“走的那两个，一人按两次。”

“他开方没有。”

“没有。”郑安说，“他进来只按了脉。按完了说一句：陛下这脉，是劳。不是病。”

林尘把手指按在自己腕上。

数六十下。一百零一。

“劳。”他说，“劳和病差一个字。”

“差一个字。”

“差一个字，走的路不一样。”林尘说，“病要太医，劳要静养。静养这两个字，谁都能说。说了就有人替朕理奏。”

他扶着案坐下。

案上有一叠文书。最上面一份是尚书台送来的，蓝布包，绳结打好，封泥还在。

“这一份什么时候到的。”

“卯时。”郑安说，“送的人没有进门，放在门房就走了。”

“哪一房的。”

“台里的。送的人说，是常例。”

林尘把封泥挑开。里面是三张纸，膳单存档，一份六月的，两份五月的。

第三张纸的背面有字。

字很小，写得密，抄了三行：

凡同验，须二人，一为国舅，一为宗正。
验毕各留副封，一藏其家，一送宗正。
三日不覆，视为未受。

三行下面是两行更小的字：

此纸自相府案抄出。原纸无印，无台号。
抄者：尚书台令史冯则。

林尘看着那三行字。

他先看第一行的最后一个字。

宗正。

然后是笔迹。

“同”字的上横他写得比别人长。“验”字右边的“佥”，他习惯把最后一撇带出去。第三行那个“覆”字，上面的“西”他写扁了，扁成一块。

他写这个“覆”字，从来是扁的。

他把纸翻过来，又翻回去。

“郑安。”

“唯。”

“这张纸，冯则怎么送出来的。”

“夹在膳单里。”郑安说，“台里往宫里送膳单存档，一月三回。他管抄。”

“他抄了九年。”

“九年，四千三百多卷。”郑安说，“台里的人说，他抄的字一眼认得出来。”

“他为什么递这个。”

“奴才问过。送东西的人说，冯则只说了一句：台里没有号的东西，不该在相府。”

“就这一句？”

“还有一句。”郑安说，“他说，他在式末添过六个字。添了六个字的人，不能装不知道。”

“所以他也认得朕的字。”

“他认得。”郑安说，“他还说了一句。他让送东西的人带话：这一份原纸在相府，不在台里。台里没有号。”

台里没有号。

没有号的东西不进档。不进档的东西不能驳，不能议，不能追。它只能被一个人拿在手里。

林尘把三张纸摆开，摆成一列。

膳单。膳单。抄件。

他把抄件单独抽出来，数了一遍。三行正文，四十七个字。两行小字，三十一个字。

四十七个字里，有六个是他自己的写法。“正”字最后一横他写得平，平得像用尺压过。

第一个判断是：这张纸是六月十四从枕下拿走的。六月十六夜里郑安出宫。三天。三天是相府一个掾从收到东西到把它变成案上一页的时间。

第二个判断是：曹操没有抓人。

他要是抓人，抓的是谁。抓一个内侍不够，抓郑安不够，抓董承要开案。开案要有罪名，罪名只有两个。

一个是矫诏。矫诏的意思是宫里有人假造诏书。那就得指出是谁造的。指不出来，这个案子立在半空。

一个是真的。真的更麻烦。真的，那这道诏要诛的人就是他。

两条都不能走。

所以他走了第三条。

“郑安。”

“唯。”

“新来的那个王医官，走的时候说了什么。”

“他说，陛下这脉要静养。他说他会把脉案送到太医院，太医院会上一份问安疏。”

“问安疏送到哪儿。”

“送到尚书台。”郑安说，“疏要录，录了才叫上过。”

“国舅府那边呢。”

“奴才昨天去过。”郑安说，“后门的门房换了人。原先的吴常不在，换了个二十来岁的，说是新买的。”

“什么时候换的。”

“前天。”

“吴常呢。”

“问了。府里的人说，吴常病了。”

“病了。”

“病了。”郑安说，“府里的人说这三个字的时候，眼睛看着地。”

“董承那边，有回话没有。”

“没有。”

“一个字都没有。”

“没有。”郑安说，“绢进了后门，什么也没出来。奴才昨天上午问，门房还说没有。下午门房就换了人。”

林尘把手指按在腕上。脉九十八。

问安疏。一份疏走尚书台，录一行。录了这一行，“陛下有疾”就有了日期。闲话成了公事。

公事一立，天子就不能视事。不能视事，奏事就要有人代。代的人是谁，疏上不写，规矩里写着。

他在这三行字上看了一会儿，看到纸边发毛。

第三个判断来得慢。

他把三行字又读了一遍，读到第一行的末尾，停住。

宗正。

他写的是宗正。

原本该是宗室。论文上写的是“一为国舅，一为宗室”。他抄的时候，脑子里想的是宗正缺三年，宗正寺的谱在相府，宗正丞站在最后一排站到散朝。

手跟着脑子走了。

“郑安。”

“唯。”

“相府那边，谁看过这张纸。”

“台里的人说，相府的一个掾昨天下午来的。”郑安说，“他把这张纸摊在台上，问了一句。”

“问什么。”

“他问：宗正缺三年，这一验是谁验的。”

殿里静下来。

林尘的手在袖子里，握了一下，又松开。

这个问题有两个答案。

第一个答案：草稿写错了。该写宗室，这里写成了宗正。

第二个答案：这张纸不是朕的。

第一个答案，他不能说。

一说，就等于认这张纸是他的，认这个错字是他写的，认这道诏是他写的。认了，后面的路是一条直线：矫诏，或者真的。真的，曹操就要自证；自证的办法，是让写诏的人先病。

第二个答案，他也不能说。

不说，这个错字就站在那里。一张自称“须宗正”的纸，而宗正缺三年，宗正寺的谱还在相府。一张自己写着“无人可验”的纸，被当作密诏送出宫。

那就成了矫制。

他坐在案前，看着那个字。

这个字是他六月十一夜里写的。写完他对着灯看了一遍，灯芯短，光小，他没有看出来。

他数了数自己认字的年头。从六岁认到现在，二十年。二十年里他抄过多少张纸，数不清。今天栽在一个字上。

“郑安。”

“唯。”

“拿笔来。”

“陛下要写什么。”

“什么都不写。”

郑安把笔端上来，放在案角。林尘把笔拿起来，在指间转了一圈，放回去。

他想写的是一张更正。八个字：宗正误，当作宗室。

写这张纸做什么。递给谁。递到相府，相府会说：这张纸是谁的。递到尚书台，尚书台会录：某人更正某纸。录了这一行，这张纸就有主了。

没有一个地方可以递。

他把笔推远一点。

他把手上能动的数了一遍。

董承，国舅，兵三百，验了一半。王子服，偏将军，兵三百，一半。刘珪，亭侯，家里四口，还没有动。郑安，黄门，十七岁。冯则，令史，抄了九年。

五个人。两个动过，一个没动，一个在跑腿，一个在递纸。

五个人，凑不齐一支符。

“王医官的脉案，什么时候送太医院。”

“今天下午。”

“太医院什么时候上疏。”

“三天之内。”郑安说，“台里的人说，问安疏要三位医官同署。”

“三位。”

“三位同署，疏才叫疏。一位署，叫方。”郑安说，“方不入档，疏入档。”

林尘把这三句在纸上排了一遍。

三位医官同署。三个人签一个名。这一套他熟。他自己写了两个月的同验，现在有人用同一套东西，把“病”变成一个有三个名字的公文。

他写程序的时候想的是让接诏的人不必一个人担。曹操用这一套，为的是让“天子病了”这一句有三个人担。

三份，三个名字，三道印。这一份他拦不住。

他能做的只有一件：弄清那份要进宫的文书抬头写什么。

“郑安。”

“唯。”

“去尚书台。不要问文书，问纸。”

“问什么纸。”

“问今天台里领了几刀纸，谁领的，领去做什么。”林尘说，“领纸要记，记了就有行。”

“唯。”

郑安去了一个时辰。回来的时候天阴了，殿里点起了灯。

“台里今天领了四刀纸。”他说，“三刀是抄录用，一刀是勘验用。”

“勘验用。”

“勘验用的纸是厚纸，一面光。”郑安说，“领纸的是相府来的一个掾，姓吕。他在簿上写的是：勘验文书，押印用。”

“押印用。”

“是。台里的老人说，勘验文书要用厚纸，因为要盖印，薄纸吃不住。”

林尘把手指按在腕上。脉九十四。

厚纸。押印。四个字。

“他领了几张。”

“一刀，五十张。”

“五十张。”林尘说，“一份勘验文书用不了五十张。”

“用不了。”

“那就是不止一份。”

郑安没有接话。

殿外的天彻底暗了。灯芯爆了一下，火苗歪了歪，又直起来。

“陛下。”

“说。”

“台里的人还说了一句。”

“说。”

“他们说，那份勘验文书已经有抬头了。抄的人抄了三份，一份留台，一份送相府，一份进宫。”

“抬头是什么。”

郑安从袖子里取出一张纸条，双手递上来。

纸条上抄着四个字。

“抄的人是谁。”

“台里的人不肯说。”郑安说，“可是他说了一句：这一份是进宫的，另外两份已经出去了。”

林尘把纸条接过来，对着灯看。

第一遍看字。第二遍看墨。墨发亮。台里用漆烟，相府用松烟。

他把纸条放在案上，用手掌压平。纸条比他的手掌短一寸。

《矫诏勘验》。

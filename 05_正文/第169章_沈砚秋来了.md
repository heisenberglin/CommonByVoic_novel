# 第169章 沈砚秋来了

六点五十。

林尘先开客服邮箱。

那个邮箱是六月注册的，挂在游戏官网上，一年九十八块。他一个星期开一次，上一次是十月六号。

未读一百七十三封。

他按时间排，从下往上翻。一百七十三封里，他回过十一封。十一封里，八封是骂人的，他回了一句“收到”。

翻到十月六号，看见三封，主题一样，三个字：第三验。

第一封，十月六日晚上九点四十。

「贵司剧本第六节写了一句『同验二人』。」

「汉制里没有这个说法。验诏是尚书台的事，宗室到场是惯例，不是制度。」

「这一条我不确定，请给出来源。」

第二封，十月八日凌晨一点二十。

「《许州志》卷十四有一条，记的是建安四年秋天的内者。」

「同一部志，我手上有三种版本。三种里有一种跟另外两种不一样。」

「我在核。核完给你看。」

第三封，十月十日下午四点。

「你没有回。」

「我打过官网留的电话，响了十一声，没有人接。」

「我下周二到江城。」

林尘把三封的时间抄在纸上。

十月六日，二十一点四十。

十月八日，一点二十。

十月十日，十六点。

三个时间，他都在许都。

十月八日那天，他坐在殿里，等一个人回来。等了两个时辰，那个人没有回来。

他把笔搁下。

从她那边到江城，高铁三小时二十分，末班二十一点四十。她昨天说“下周二到”，今天周三。她在这边过了一夜。

旅馆钱她自己出的。他算了一下：最便宜的一晚一百六十八，加来回车票，这一趟四百多。

四百多块钱，是来看三个字。

他回了一封，两行：

「沈老师，我在。」

「今天几点都行。」

发出去。七点零一分。

他把客服邮箱的提醒打开，勾上新邮件短信通知，保存。保存完坐了一会儿，把勾去掉，又打上。

九点十分，门铃响。

两下。间隔一样长。

林尘开门。

沈砚秋站在门口。还是那件外套，还是那个筒。筒今天没有背在肩上，是提在手里的，提手断过，用一截铁丝缠住。

“我九点零二分看见你的回信。”她说，“我在楼下。”

“上来。”

“我上来了。”

她进门，把筒放在桌上，没有坐。

“今天先给你看东西。”她说，“看完你再决定说不说。”

她解开筒口的胶带。胶带三圈，缠得很紧，解的时候她用指甲一点一点抠。

筒里三样。

一卷拓片，牛皮纸包着，两头塞了报纸。

一叠A4打印纸，长尾夹夹着，夹子上有一道划痕。

一个硬纸板夹，A3大小，边上磨得起毛。

她先把那卷拓片拿出来。

牛皮纸摊开，里面是一层棉纸，棉纸摊开，是一张拓片。黑底白字，高四十公分，宽二十五。

十七行隶书。字口很深，有几处洇了。

“这个我拓的。”她说，“十年前，我第一次下田野。”

“在哪里。”

“鲁地一个县的文管所。碑在院子里，当石凳用，上面搁了三个花盆。”

她把拓片铺平，用手掌从中间往两边压。

“看最后一行。”

林尘低头。

最后一行三个字：制曰可。

“你剧本里写诏，最后一句也是这三个字。”她说。

“是。”

“这三个字我在拓片上见过一百多次。”她把拓片往他那边推了推，“再看上头那三行。”

上头三行是三个官名，后面各跟一段话。字小，隶书压得紧。

“一件小事。”她说，“一个县要添一个管礼器的吏，为这件事，三个公上了奏，天子回了三个字。为一个人，走完了整套。”

“走完了就成。”

“走完了就成。”她说，“你剧本里写诏，前头也有一句‘三公同奏’。从‘三公同奏’到‘制曰可’，六个字。你写对了六个字。”

“六个字够什么。”

“不够。”她把拓片卷起来，“可是对一次是一次。我来不是全盘否你。我否的是你没写对的地方。”

她把A4那一叠抽出来，放在桌上，转过来对着他。

“这个我做了八年。”

一张表。两栏。左栏是词，右栏是出处。

十七行。

验诏。覆奏。封还。留中。副署。录副。符节。传信。案比。刻奏。白事。移书。举劾。案验。参验。复验。校验。

每一行右栏都有出处。《续汉志》，《汉旧仪》，《后汉书》，一条一条，卷数页数都写着。

十七行，没有一个空格。

“十七个词。”她说，“汉制里都有。出处我一条一条核过，最短的一条核了两个月。”

“我可以挑一个问。”

“挑。”

“参验。”

“《汉旧仪》卷上，第十一页。”她报得很快。

“白事。”

“《续汉志·百官志》，第三十六页。”

“校验。”

她停了半秒。

“这一条我不确定。”她说，“出处是一个唐人的注。唐人注汉制，隔了四百年。”

林尘看着第十七个词。

“你敢说不确定。”

“不确定就是不确定。”她说，“我把不确定的三个字写在这一行的后面，写了两百多行，只有这一行写上去过。”

“再问一个。”他说。

“你问。”

“密诏出宫，用不用符节。”

“不用。”她说，“符节是驿传用的。诏出宫凭的是玺，不是节。”

“出了宫，凭什么叫人信它是诏。”

“凭三样。玺。副署。留台的那一份。”

“三样都齐了，还是有人不信。”

“那就叫第四样。”她看着他，“第四样是接诏的人自己愿不愿意信。”

林尘没有接。

“这一问难住你了。”

“没有。”

“那你为什么停了两秒。”

她把这一问答记下来。记完在旁边画了一个小方块，方块空着。

“这个方块是什么。”

“是没有答案的意思。”她说，“我记了八年，画了十一个。”

“第十八个呢。”他问。

“第十八个没有出处。”她把纸往他那边推了推，“第十八个是你那三个字。”

林尘把那张表从头看到尾。

“八年。”

“八年里我核出十七个。”她说，“每一个都有出处，每一个都能引。第八年的时候我明白一件事：这十七个，都是有人做过的。没有人做过的，不会写进书里。”

“所以第三个验是没人做过。”

“不是没人做过。”她说，“是没有这个位置。”

“这张表，你做给谁看的。”他问。

“给我自己。”

“为什么。”

“我在写一本书。”她说，“这个题目一九九八年有人用过，写了四十二页。我写到三百一十页。”

“书名。”

“《汉魏诏令传递考》，增订本。”

“出版了吗。”

“退过两次。”她说，“第一次说题目太窄。第二次说结论太硬。”

“哪个结论。”

“‘此制未行’四个字。”

“为什么太硬。”

“审稿的人说，一个制度没有落地，不等于它没有存在过。”她说，“他说得对。我改了三个月，改成‘此制未行，然其文具在’。”

“改完呢。”

“还在等。”她说，“等一条新证据。”

“你师兄看过没有。”

她把表往回收了一下。

“罗振声看过前三章。”她说，“他说我这本书出了，他那本就不用出了。”

“他怎么说的。”

“他请我吃了顿饭。”她说，“饭桌上说了两次‘我理解’。”

她把长尾夹松开，把那张表收回去，夹好。

“那篇论文的作者姓沈。”他说。

“嗯。”

“沈承业。”

“嗯。”

“他是你什么人。”

她把笔帽盖上。盖了两次才盖上。

“这一条我不答。”

“为什么。”

“因为答了，后头的话你就不听了。”她说，“你会开始算我说的哪一句是替谁说的。”

林尘把这一问咽回去。她看见他咽，没有说。

“我这一趟，只核一件事。”她说，“建安四年九月，许都杖死过一个内者吗。”

林尘没有立刻答。

他在心里算。

第一，说出来，她下一个问题一定是“你怎么知道”。答不出，她会记下“不能说”三个字。昨天她记过一次。

第二，她会去查“郑安”两个字。许都的内者名册没有传下来。黄门的名籍在少府，少府的簿子过两百年就没了。她查不到。

第三，查不到的名字，在她那里等于编的。

说不说都一样。说了是编的，不说也是编的。

三步算完，他把话咽回去。

“有。”他说。

“几个。”

“一个。”

“多大。”

“十七。”

“叫什么。”

林尘没有答。

她等了五秒，没有催。

“你知道。”她说，“你知道，你不说。那就够了。”

她把那个硬纸板夹拿过来，放在桌上，两只手压在夹子上。

“我不问名字。”她说，“我问另一件。”

“问。”

“他家里有几个哥。”

林尘把手从桌沿上拿下来，放在膝盖上。

窗外有人在楼下卸货。卷帘门的铁链响了一下，箱子落地，闷的一声。

“你问这个做什么。”他说。

“因为名册传不下来，兄弟能传下来。”她说，“内者的名字留不住。兄弟在哪一郡，当没当差，走没走过汉中那条道，会留在别的东西里。”

“什么东西。”

“方志。”她说，“方志不记内者，方志记地方。一个颍川人，两个哥哥，一个在颍川，一个在汉中。这种人在方志里不写名字，写‘某’。”

她把夹子打开。

一张A3，影印，纸是灰的，字是黑的，边上有一道复印机压出来的黑边。

一条，用红笔圈着。圈画得不圆，起笔和收笔没有接上。

“《许州志》，康熙九年刻本，卷十四，第四十一页。”她说。

“我找这一页，找了两个月。这部志全国存七部。六部在公家，一部在私人手里。我看的是私人那一部，人家许我看两个钟头，不许拍照，许我抄。”

“私人那一部怎么看到的。”

“在一个收旧书的人手里。”她说，“我给他打了十七个电话，他接了第九个。”

“两个钟头抄了多少字。”

“六十二个。”

“为什么只抄六十二个。”

“因为两个钟头只够抄六十二个。”她说，“我抄的时候先抄年号，再抄人名，最后抄数字。六十二个字里，有四十一个是年号和页码。”

“剩下二十一个呢。”

“剩下二十一个在这一条里。”

“这两页是我照抄的。抄完我自己排的版，排成书的版式，印出来对一遍。”她说，“所以这上头每一个字的间距，都是我自己调的。”

“为什么要调。”

“因为我要看它像不像真的。”她说，“抄出来的东西最容易出的事，是抄的人把它抄得比原本好看。”

她把A3转过来，正对着他。

“为什么给我看这个。”

“因为你看得懂。”

“看得懂的人多。”

“看得懂又写得出的人不多。”她说，“写得出还肯认的人，更少。”

“我认什么。”

“认你没写过这一条。”她说，“认完再谈别的。”

“这一条，我念给你听。”

「有黄门某，杖死，籍其家。家有二兄，一在颍川，一在汉中。」

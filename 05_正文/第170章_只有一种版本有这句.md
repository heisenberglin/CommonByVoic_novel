# 第170章 只有一种版本有这句

下午一点四十。

林尘重新打开后台。

【历史节点：许都·建安四年九月｜判定：未完成｜世界线偏移：1.20%】

【今日可下旨次数：1,612。今日已用：1。】

他把后台关掉。

桌上三个泡面盒，昨天的、前天的、大前天的。他把盒子摞起来，摞成一根，端到厨房，扔进垃圾桶。回来的时候手上有油，他在裤子上擦了两下。

茶几不够大。他把餐桌上的东西全挪到地上：一箱打印纸，两个硬盘，一台旧显示器，显示器上面搁着一只袜子。

铺了三样东西上去。

第一样，她抄的那一页，A3，她自己排的版。

第二样，一张复印件。道光二十三年刻本，卷十四，第四十一页。纸是从图书馆的数字库里打印的，右下角有水印，浅浅的一行字。

第三样，一本油印本。一九五九年，纸是黄的，装订是三个订书钉，钉子生了锈。封面上有一个手写的编号：零七四。

“油印本哪来的。”

“我买的。”她说，“孔网上，一百二十块。卖家说是从一个县文化馆处理出来的。”

她从包里拿出一把尺。透明的塑料直尺，一头磨白了，刻度到十五公分就没有了。

她把尺横在三张纸上，一行一行往下推。

“看版框。”她说，“康熙本高二十公分。道光本高十八公分半。油印本是照着道光本缩的，十七公分。”

“行数呢。”

“三个本子都是一行二十四字。”她把尺挪开，“字一样，行不一样。康熙本一页十九行，道光本十八行，油印本照道光本，也是十八行。”

她把三张纸并排。

康熙本那一页，十九行。

道光本那一页，十八行。

“数行。”她说。

林尘从第一行数起。

康熙本第十一行，就是那一句。

道光本第十一行，是“九月，大水”。

“少了一行。”他说。

“少的是一行。”她把油印本推过来，“你自己数。”

油印本那一页，十八行。第十一行也是“九月，大水”。

“三种版本，只有一种有这句。”她说，“康熙九年，一六七〇年。道光二十三年，一八四三年。中间隔了一百七十三年。”

“道光本是重刻。”

“重刻。”她把复印件翻过来，背面是凡例的一页，“凡例第五条：旧板漫漶，今重梓。”

“重梓就是重刻。”

“重梓是照旧本重刻。”她说，“旧本上缺一行，重刻出来还是缺一行。刻工不会替你补。”

林尘把三张纸对齐，让三页的第十一行落在一条竖线上。

康熙本：有黄门某，杖死，籍其家。家有二兄，一在颍川，一在汉中。

道光本：九月，大水。凡伤稼八百顷。

油印本：九月，大水。凡伤稼八百顷。

“八百顷。”他说。

“三个字都是抄的。”她说，“油印本的整理者在前面写了一段话，我念给你听。”

她翻到油印本前面，找到那一段，用手指压住。

“卷十四第四十一页下半残，据道光本补录。”她念完，把手拿开，“他在前言里写了这一页半残。他补的时候，也只补得出道光本有的东西。”

“有没有可能，”林尘说，“康熙本这一行是后人添的。”

“可能。”她说。

“有没有可能是抄错。抄的人看错了一行，多抄了一行。”

“多抄一行，纸上要有一个字的空位。”她把康熙本那一页翻到正面，“你看这一行。二十四个字，顶格起，顶格到底，一个字不多，一个字不少。抄错会挤，添字会补在行末，会有一个字的空。”

林尘数了一遍。二十四个字。

“还有。”她说，“这一行前头是‘九月，大水’，后头是‘十月，疫’。志里的纪事按月排，九月一段，十月一段。中间插一个内者，插得没有道理。”

“没有道理，也可能是真的。”

“也可能是真的。”她说，“所以我不替它下结论。”

“你怎么排掉‘后人添的’这个可能。”

“我排不掉。”她把眼镜摘下来，放在桌上，“我只能排掉一半：这一行不是我的时代添的。道光本没有，油印本没有。要添，只能在一六七〇和一八四三之间添。”

“一百七十三年。”

“一百七十三年。”她说，“这一百七十三年里，能出两种解释。第一种，有人在一部康熙本上添了一行。第二种，有人在一部康熙本上铲了一行，道光本就是照铲过的那一部刻的。”

“你分不出来。”

“我分不出来。”她说，“所以我不下结论。我只把三种版本摆出来。”

“摆出来给谁看。”

“给看得懂的人看。”她说，“一百个看得懂的人里，有一个肯去调另外一部康熙本，这件事就有结论。调不到，这条就一直挂着。”

三点十分，她在一个论坛上发了一个帖子。

论坛叫“文献整理与地方志”，注册要审核，注册人数不到四千。她的账号注册十一年，发过一百四十七个帖子，被删过两个。

帖子标题：《许州志康熙本一条，三种版本互异，求教》。

正文八百字。附三张图，一张一张对得整整齐齐。

“为什么不发在大一点的平台。”

“大的平台不看这个。”她说，“大的平台看标题。”

三点四十，第一条回复。

四点十分，十一条。

五点，四十七条。

六点，六十七条。

林尘一条一条看完。

骂她编的，五十二条。

说她拿假图的，八条。

认真问出处的，三条。

剩下四条是广告，卖拓片，卖家谱，卖高仿的汉砖。

第五十一条他读了两遍。

「这一句我在一个游戏里见过。」

「楼主是不是玩游戏玩出来的。」

这条底下有三个人点赞。

林尘把这一条截图，存进“记者”那个文件夹。文件夹现在有十四张。

沈砚秋也看见了。她往下拉了两次，把这一条又拉回来，看了很久。

“你回不回。”他问。

“不回。”

“为什么不回。”

“回了就是承认我看过那个游戏。”她说，“看了游戏再看方志，我这条就成了从游戏里倒推出来的。”

“六十七条里，有几个去查了。”他问。

“三个。”

“三个里，有几个说你对。”

“零个。”

“为什么。”

“因为他们查不到康熙本。”她说，“全国七部。六部在公家，一部在私人手里。公家那六部，要单位介绍信，要约时间，要等。等一个月，能看两个钟头。”

“所以他们没有查，就说你编的。”

“他们没有说他们没查。”她说，“他们说的是‘这一条不见于通行本’。”

六点二十，有人把帖子截图转到了另一个平台。

七点，转第十一次。

七点十分，她接到一个电话。

她看了一眼号码，站起来，走到阳台上。

阳台的门没有关严。林尘听见她说话，一共说了四句。

“是我发的。”

“图是我拍的，版是我排的。”

“不删。”

“罗老师，我不是学生了。”

电话挂断。她在阳台上站了一会儿，进来，把手机放在桌上，屏幕朝下。

“罗振声。”

“嗯。”

“他说什么。”

“他说这一条如果是错的，我这本书就废了。”她坐下来，“他说得对。他还说，我这本书废了，他那本就能出。”

“哪一句是真的。”

“两句都是真的。”她说，“他是我师兄。他帮过我看稿。”

七点四十，出版社的编辑打电话来。

她这一次没有去阳台。她坐在桌子对面，一句一句答。

“是。”

“三种版本里只有一种有。”

“我没有撤稿的打算。”

“我知道会推迟。”

“推迟就推迟。”

挂断，她把这个号码存进通讯录，存完看了一眼，又删了。

“合同签了几年。”他问。

“三年。”她说，“二〇二四年签的。交稿日期十二月三十一日。首印三千。”

“定金拿了多少。”

“五千。”

“推迟了要不要退。”

“合同里有一条，交稿推迟超过六个月，出版社可以解约，定金不退。”她说，“我没有违约，是我交不了稿。交不了稿不算违约，算我拖延。”

“拖到什么时候。”

“拖到他们不等了。”

“首印三千。”林尘说，“六千人骂你，里面有几个会买你的书。”

“三个。”

“哪三个。”

“我老师，我师姐，我自己。”

“一本多少。”

“八十八。”

“两百六十四。”他说，“三百本书的版税，按百分之八算，七百零四块。”

“你算这个做什么。”

“我在算你这一条值多少。”

“这一条不值钱。”她说，“它要是真的，值一本书。它要是假的，值一个账号。”

“掉了多少人。”他问。

“什么。”

“这个帖子。你原来有多少人看你的东西。”

“一百多个。”她说，“一个帖子二十几个阅读。”

“现在呢。”

“六千四。”她说，“其中六千人骂我。”

“删不删。”他问。

“不删。”

“为什么不删。”

“删了就是我认了。”

“这六千四百个人会一直记得。”他说，“你现在删，帖子还在别人的截图里。你删的是你自己的账号，不是那句话。”

她看着他。

“你在劝我删。”

“我在算。”他说，“删了，你损失一个账号。不删，你损失一本书。”

“书推迟，不是损失。”她说，“书废了才是损失。书废不废，要看这一条是真是假，不看多少人骂。”

“我再算一个。”他说，“你不删，六千四百个人里，会有几个去看第四十一页。”

“零个。”

“那你还发。”

“我发的时候不知道是零个。”她说，“现在知道了。”

“知道了还留着。”

“留着。”她说，“留着，是因为三个人问了出处。三个人里，有一个问得对。”

“他问什么。”

“他问：康熙本的纸，是开化纸还是竹纸。”她说，“这是内行问的。开化纸的康熙本，全国剩不到三十部。他一句话就把范围缩到了三十部。”

他把三张纸收起来，摞齐，放回她那边。

“我有一件事没弄明白。”他说。

“说。”

“你为什么来找我。”

“我不是来要你证明我对的。”她说，“我是来问你一件事。”

“问。”

“你那个游戏里，为什么有一个 NPC 叫第三验。”

林尘的手停在纸上。

“我剧本里没有这三个字。”

“我搜过。”她说，“你那个游戏，汉线剧本，第七节，宫门那一关，有一个内者，站在门里。点他，他说一句话。”

“什么话。”

“‘第二验死了，谁来做第三验。’”

“你玩到第七节，用了多久。”他问。

“四十分钟。”

“为什么记得这么准。”

“因为核东西要记时间。”她说，“哪一页，看了多久，中间歇了几回。我记了八年，改不掉。”

“歇了几回。”

“零回。”她说，“我一次坐到底。”

屋子里静了几秒。

楼下有人在收摊，铁架子的腿刮着地，一声一声。

“那个 NPC 叫什么。”他问。

“名单上写的是‘内者·甲’。”她说，“玩家管他叫第三验。”

“我剧本里没有这个。”

“你的剧本里有。”她说，“我玩了四个钟头，第七节过不去。我回头点了他七次，七次都是这一句。”

林尘把手机拿过来，手指停在屏幕上。

“你现在要做什么。”她问。

“看我的游戏。”

# 第181章 七个 IP

十月二十七日上午八点四十，林尘打开邮箱，有一封。

发件人是应用商店内容合规组，主题比上一封短：复查通知。

他把正文打印出来，一页。

第一段写原受理编号，第二段写复查事由，第三段写要求。

复查事由那一段只有两行：举报人于十月二十日补充材料，指该应用整改不实，具体指“黄门阿禾”一处。

林尘把“整改不实”四个字圈起来。

八月他交的说明里，第二处写的是“阿禾为原创人物，非史实人物”。平台当时认了。

现在有人拿出新材料，说这一处不实。

他往下看期限。

三个工作日。

十月二十七号是星期二。三个工作日，到十月三十号。

和市局那封同一天。

九点半，苏晚到。

她今天带了笔记本，没带伞。

“两封。”

“两封。”林尘说，“一封要三个名字，一封要一句说明。都到三十号。”

苏晚把两封并排摆开，先看平台那封。

“复查和第一次不一样。”她说，“第一次是核查，核查有期限，期限到了它必须给结论。复查没有期限，复查不给结论，它只做一件事。”

“什么。”

“把你的答复和举报人的材料放在一起，看对不对得上。”她说，“对不上，直接转下架，不再通知。”

“八月我们交的说明，是我写的。”

“平台认了。”苏晚说，“认了不等于对。它当时只看了你一面。”

林尘把“阿禾”那一段翻出来。

“这一处我答不上来。”

“我知道你答不上来。”苏晚说，“所以这一封不能答。这一封要用另一种办法过。”

“什么办法。”

“三十号之前，让市局那封先过。”她说，“市局过了，平台会等。市局不过，平台不用等。”

十点，林尘把七个 IP 按时间排开。

后台二〇二五年加过一张会话表，记进和出。他自己写的，字段五个：账号、IP、进、出、操作数。

他把 read class 的会话全拉出来，一屏。

第一条：六月十八日二十二点十一分，他家宽带，进，出。

第二条：六月十九日二点四十七分，113.57，进。

第三条：六月十九日三点十二分，113.57，出。

第四条：六月十九日三点四十，117.136，进，出。

第五条：六月十九日四点零五，202.110，进，出。

第六条：六月十九日十三点二十，他家楼下咖啡店，进，出。

第七条：六月二十日九点零三，他自己的手机，进，出。

第八条：十月十九日二十三点四十七分，47.98，进，出。

林尘数了一遍。

八条记录，七个地址。

第二条和第三条是同一个地址，两次登录。他把这两条用括号括在一起。

七个地址里，三个是他的：家里的宽带，楼下咖啡店的无线，他自己的手机。

四个不是。

十点十分，他算会话时长。

六月十八日二十二点十一分到二十二点三十六分，二十五分钟。他那天在配权限，配完截了图。

六月十九日二点四十七分到三点十二分，二十五分钟。周工第一次查。

三点十二分到三点四十，二十八分钟。周工第二次查，然后导出。

三点四十到三点四十四，四分钟五十一秒。移动网络。

四点零五到四点零九，四分钟十二秒。图书馆。

十月十九日二十三点四十七分到二十三点四十七分十一秒。云机房。

林尘把最后这一行看了三遍。

十一秒。

十点二十，他查图书馆那个地址。

202.110 这个段，归属是江城图书馆，江北区。

他打图书馆的总机，转技术部。

“我想问一下，六月十九号凌晨四点，你们馆里的公共终端有没有开机。”

“凌晨四点我们闭馆。”

“闭馆了机器关不关。”

“不关。”对方说，“机器不关，网断。早上八点开。”

“六月十九号早上八点，有没有人用三号机或者四号机。”

那头笑了一下。

“我们一天三百多人上机，你问一台机器。”

“上机要登记吗。”

“刷身份证。”他说，“记录存三天。”

“六月十九号的记录，现在是十月。”

“那就没有了。”对方说，“三天，多一天都没有。”

林尘把电话放下。

十点四十，他查启元那个地址。

113.57，启元办公网。

这个段他认识。六月十八号他去过一次，十七层，前台挂着三块铜牌。

一个出口 IP，一栋楼，四百多个人。

他查了一下启元现在的规模：参保人数三百七十九。

三百七十九个人共用一个出口。要查出哪一台机器，要么有他们的网关日志，要么有法院的调证令。

两样他都没有。

十一点，他查那个机房地址。

47.98，浙江，机房段。

他在一个查 IP 的网站上输了这串数字，出来三行：运营商，机房，用途。

用途那一栏写着：IDC。

下面一行小字：该段由某某数据服务有限公司持有。

他搜这家公司。公司做的是数据采集和代理，注册地在一个产业园，注册资本一千万，参保人数十一。

他打客服电话。

“我想查一个 IP 的租用方。”

“可以。”对方说，“请提供公检法手续，或者权利人证明。”

“什么算权利人。”

“被侵权的一方，要有立案证明。”

林尘把这句话抄在纸上。

立案证明。他昨天刚算过，他不能立案。

十一点二十，他把四条路并排写在纸上。

启元办公网，查不到人。

本地移动，查不到人。

图书馆，记录存三天，过期了。

云机房，要立案证明。

四条路，四条断在同一个地方：他没有资格查。

十一点四十，林尘点开四点零五分那条记录，把查询语句展开。

后台的审计日志存语句，这是他自己加的，加的时候只为了调试。

语句出来了，一行：

SELECT id, created_at, in_world_at FROM log_edict ORDER BY in_world_at DESC LIMIT 9。

他盯着这一行，看了很久。

ORDER BY in_world_at DESC。

按世界内时间倒序。

LIMIT 9。

取前九行。

四十一行里，世界内时间最长的是八十七天。按倒序排，前九行就是最长的九个。

他把这一行抄在纸上，抄完在旁边写：

这个字段叫什么，查的人未必知道；要按这个字段排序，他清楚。

中午十二点，苏晚回来了。

她手里拿着一个信封。

“平台的第二封，纸质的。”

“邮件已经收到了。”

“纸质的今天到。”她把信封放在桌上，“同一天，两封，一封邮件一封挂号。他们做了两手。”

林尘把信封翻过来，看邮戳。

十月二十五日，江城本地。

“二十五号寄的。”他说，“二十五号是星期天。”

“星期天他们也寄。”苏晚说，“这一封不是流程，是有人催出来的。”

“催的人是谁。”

“不知道。”她说，“催的人知道三十号这个日子。”

林尘把邮戳那一块用手机拍了照。

十二点二十，他把那四个不是他的地址又看了一遍，看到最后一条。

十月十九日，二十三点四十七分，云机房，十一秒。

十月十九日。

他翻笔记本，找那一页。

十月十九日，沈砚秋来他这里看史料库。下午两点到，六点十分走。她在的时候用他的电脑，用的是访客账号，只能看史料库，进不了后台。

她走的时候，他把门送到楼梯口。

六点十分。

二十三点四十七分。

林尘在纸上写两行：沈，18:10。云，23:47。

写完他在两行中间画一道线，写上五小时三十七分。

这条线不成立。她走了以后就不在江城，第二天早上九点她发过一条消息，说在回学校的高铁上。

他把这一页划掉。

划完他停了一下。

他刚才差点把一个来核他的人，算成来偷他东西的人。

苏晚看着他划。

“你算过她。”

“算过。”

“算完呢。”

“划掉了。”

“划掉的理由要写下来。”苏晚说，“下次你还会算她。写下理由，你就不用重新算一遍。”

林尘在那一页背面写：十月十九日十八点十分离开，次日九时在高铁。云机房会话二十三时四十七分，地点不符。

写完他签了一个日期。

十二点四十，他把那张写着查询语句的纸推给苏晚。

苏晚看了两遍。

“这一句说明什么。”

“说明查的人知道该查什么。”林尘说，“六月十九号凌晨四点零五分，一个不知道后台结构的人，不会想到按世界内时间排序。”

“周工知道。”

“周工三点四十七上的车。”林尘说，“行程单我看过。”

“那就是另一个人。”

“另一个人，用同一个密码，在同一台机器上，或者另一台机器上，做了周工没做的事。”

苏晚把纸放平。

“这条能写进材料吗。”

“不能。”林尘说，“这一条只能证明有人查过。证明不了是谁。”

“那就还是没用。”

“有用。”林尘说，“它证明这个人手里有账号，而且这个人清楚这个账号能看到什么。”

下午一点，林尘把会话表又拉了一遍，按 IP 分组。

四个不是他的。

113.57，两次，合计五十三分钟。

117.136，一次，四分五十一秒。

202.110，一次，四分十二秒。

47.98，一次，十一秒。

他把四行抄在纸上，抄到第四行停住。

十一秒。

他起身去开那个抽屉。

抽屉最底下压着一个本子，七月十九日在高铁上写的。他翻到最后几页。

七月十九日那一页，他记过一个账号：四道旨，每道十一秒。二十一点十四分零七秒进，二十一点十四分十八秒出。

写一个字，点提交，等判定，退出。

判定要十二秒。它不等。

林尘把本子摊开在键盘上，跟屏幕上那一行并排。

六月十九日凌晨，云机房，十一秒。

八月，每天晚上二十一点十四分，十一秒。

他把笔拿起来，在两个“十一秒”中间画了一条竖线。

竖线画到一半，笔尖断了。

他换了一支笔，在竖线底下补了一行：

设备号空。来源空。十一秒。

七月十九日那四道旨的后台记录，他翻出来看过很多次，设备号那一栏是空的，来源那一栏是空的。

现在这一条也是。

林尘把本子合上，压回抽屉，抽屉推到底。

下午一点四十，他打开后台首页。

【世界线偏移：1.28%｜判定：未完成】

【在线：1,652｜昨日：1,706】

【今日可下旨次数：1,652。今日已用：0。】

林尘把“1,652”抄在纸上。

一天掉五十四。

他把这个数写在那一行“十一秒”下面，两行并排，中间空一行。

写完他看了一会儿，把纸推到桌角。

桌角那一叠是复印件，三份。最上面一份的右下角有一行浅灰的字。

他拿放大镜对着那一行。

0612。

林尘把放大镜放下，两只手按在桌沿。

桌上有两样东西是一个人的：一行工号，一个十一秒。

他把那一行工号抄在纸上，抄在“十一秒”下面，中间空一行。

抄完他把纸对折，压在本子底下。

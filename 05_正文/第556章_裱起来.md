# 第556章 裱起来

八月一日，早上八点四十。公司三楼。

林尘把回复函的第一稿摊在桌上。三十一页，装订机打的孔，两个孔，孔边有毛。

苏晚站在桌对面，手里一支笔，笔帽咬在嘴里。

“写到第几条了。”

“七十一。”苏晚把笔帽拿下来，“一百一十三，写完七十一。剩四十二。”

“哪四十二条没写。”

“没有凭证的那九条，加原件没见过的四条，加十八条只拍到照片的。”苏晚说，“这四十二条最难写，因为每一条都要写一句‘未能取得进一步证据’。”

“三十一页够不够。”

“不够。”苏晚说，“按现在这个写法，全稿要五十一页。回复函超过五十页，交易所会另附一份摘要，摘要谁写，他们写。他们写出来是什么样，我们控制不了。”

“那就压到五十页以内。”

“压了就要删字。”苏晚说，“删字就是删证据。”

“删描述，不删证据。”林尘说，“每一条三栏，一栏一行。别写句子，写词。”

九点二十，他打了一个电话。

号码是江城老城区一家旧书店的，店主姓闻，七十一岁。

“闻先生。”

“你讲。”

“回复函里要写来源。”林尘说，“您那三条，我要写您的名字，还要写取得方式。”

那头静了一会儿，有翻书的声音。

“我父亲留下的。”老人说，“三张，一张是契，两张是信。”

“我知道。”

“你要写我的名字，我没什么。你要写我父亲的名字，我不愿意。”

“可以不写。”林尘说，“写‘闻氏旧藏’。”

“闻氏旧藏。”老人重复了一遍，“这四个字，别人一看就知道是我家。”

“那我就写‘持有人要求隐去姓名’。”

“那三条，你怎么说明来源。”

“写‘二〇二六年三月，经江城旧书店闻氏转让，转让凭证为手写收据一张’。”林尘说，“收据在，编号 0-17。”

“收据你留着。”

“留着。”

“那你写吧。”老人说，“别写我爸的名字。”

十点，他叫陆嘉上来。

“查一样东西。”林尘说，“二〇二六年六月十号，我邮箱里收到的第一封律师函。发件人明衡，主题里有‘启元’两个字。”

陆嘉把笔记本打开，连上公司邮箱。

“个人邮箱还是公司邮箱。”

“那时候还没有公司邮箱。”林尘说，“用的是注册游戏账号那个。”

“哪个。”

“linchen 加六个数字那个。”

陆嘉敲了几分钟。

“删了。”他说。

“什么删了。”

“服务器只留十二个月。”陆嘉说，“二〇二六年六月的邮件，二〇二七年六月就清了。你那个邮箱是免费邮箱，清理前不发通知。”

“备份呢。”

“没有备份。”陆嘉说，“你那时候没做备份。第一次备份是二〇二六年十月的硬盘。”

“手机上呢。”

“手机只同步最近三十天。”陆嘉说，“除非你手动存过。”

林尘把手机翻出来，打开相册。

“存过一张。”他说。

“那就只剩一张。”

十一点，苏晚把第三批回执拿上来。

三十二张，A4 的一半，一张一家。四十一家里已回三十二家，九家没回，其中三家电话是空号。

“空号那三家，合同上是怎么写的。”林尘说。

“写的是书店地址。”苏晚说，“我让人去看过，三家都拆了。”

“那就写‘地址已拆，无法联系’。”

“写了，交易所会问为什么不早联系。”

“写‘二〇二六年取得时已联系，二〇二七年七月再联系，地址已拆’。”

“这样写，等于自己承认这九条没有核实过。”

“承认。”林尘说，“九条单列。”

苏晚把那三十二张回执按编号排好，用长尾夹夹住。

下午三点，他下楼取框。

店里的胶味比上次重。柜台后面立着一个框，靠墙放着，正面朝里。杭师傅把框转过来。

实木，深褐，四边各宽三公分。框里那张 A4 压在一层白卡纸上，四边留两公分。玻璃反光，能看见店门口的街。

“五百六。”杭师傅说。

林尘扫码，付了六百。杭师傅从抽屉里数出四张十块的，压在柜台上，一张一张推过来。

杭师傅正在给一张旧画托纸，糨糊刷在案子上，刷得匀。

“我一九九八年给省图修过一批民国报纸。”杭师傅说，“那时候学的一个法子，就是用紫外灯看纸。老纸新纸，一照就分得出来。”

他把手电从柜台底下拿出来。黑的，比手指粗一点。

“验钞的。”他说，“三百六十五纳米。”

他把店里的灯关了。屋里暗下来，只剩街上的光从玻璃门进来。他打开手电，光落在框里的纸上。

纸面亮起来，是一种发蓝的白。

“看见没有。”杭师傅说，“这个亮。”

“亮了说明什么。”

“说明纸里有荧光增白剂。”杭师傅说，“二〇二〇年以后的书纸、打印纸，都加这个。加了看着白。老纸没有，老纸照上去是暗的，发黄，发灰。”

他把手电移开，又照在框边一张旧纸上。那张纸是暗的。

“这张纸的荧光，是新的配方。”杭师傅说，“我做这行四十年。这种亮度，是这两年的纸。”

“这张纸是二〇二六年的。”

“二〇二六年的纸，二〇二六年印，也对。”杭师傅说，“可纸龄不对。这张纸太新。像今年新印的。”

灯开了。店里亮回来。

林尘低头看框里的落款。

明衡律师事务所。落款日期：二〇二六年六月十二日。

他记得六月九日。

他从口袋里拿出手机，翻相册。相册按日期排，他往下翻，翻到二〇二六年六月十日。那天早上七点四十一分，他拍过一张照片。照片里是一封律师函，摊在出租屋的桌上，落款日期：二〇二六年六月九日。

他把手机举到框边上，两张并排。

六月九日。六月十二日。

“三天。”他说。

“什么三天。”

“没什么。”

三点二十，他给苏晚打电话。

“二楼档案室。”他说，“其他-07，我要看。”

“档案不外借。”

“我下去。”

“三点半。”苏晚说，“我三点半到。”

三点半，二楼档案室。

二十三平方米，四组铁柜。苏晚把钥匙从腰上解下来，开第三组柜，第二层，从左数第七格。格子上那块小牌还在：其他-07。

她把盒子端出来，放在长桌上，打开盖。

欠条在最上面。A4，四折，折痕发白。她把纸展开，四角压上四个铜镇纸。

“你要看什么。”

“你念。”

苏晚低下头，一行一行念。

“欠陈演一副下联。”

“欠阿禾一个名字。”

“欠周允之三页。”

“欠何九鼎一个孙女。”

她停住。

手指停在第五行上面，没有落下去。

“这一行的字我认得。”她说，“我不记得我见过。”

“七月九号你念过。”林尘说，“你还问了一句，顾淮是谁。”

苏晚把眼睛移到纸上，看了两秒。

“我不记得。”她说，“字我认得。我问过，我不记得。”

“再看一遍。”

她看了。看的时间比前四行长。

“欠顾淮一个名字。”她念，“七个字。”

“嗯。”

“我数过一张这样的纸。”苏晚说，“四月二十八号。四行，二十八个字，加最上面那个‘欠’，二十九个。”

“现在三十六。”

“三十六。”她说，“那不对。我数的不是这张。”

“你数的是这张。”

“我数的是四行。”苏晚说，“这张五行。”

她把铜镇纸挪开一个，把纸的右下角翻起来，看背面。背面是白的，什么都没有。

“这一行是后加的。”她说，“加的人字写得比你稳。”

“我写的。”

“你写的。”她重复了一遍，“那我是忘了。”

她把铜镇纸压回去。

“何九鼎我认得。”她说，“陈演是谁。阿禾是谁。周允之是谁。顾淮是谁。”

“陈演是明朝一个官。”林尘说，“阿禾是秦朝一个书吏。周允之是宋朝一个押粮的。”

他停住。

“顾淮呢。”苏晚说。

“是一个写字的。”

苏晚看了他两秒，没有再问。她把欠条按原折痕折起来，四折，折得齐，放回盒子里。

“为什么不裱这张。”她说。

“还在还。”

“还谁。”

“五个人。”

“还到哪一步了。”

“一个名字刻上去了。”林尘说，“三页重写了。下联补了。孙女找到了，不是原来那个。第五个，名字写进名录了。”

“那不就还完了。”

“没有。”林尘说，“刻上去的名字没有姓。重写的三页第一行写着‘未还’。补的下联不是好句。找回来的孙女不认他。写进名录的那个人，人不在了。”

苏晚把盒盖扣上。

“我听懂了。”她说，“你这张纸，是记着还不掉的。”

“是。”

“那更该裱。”

“不裱。”林尘说，“裱起来就成了一件东西。它现在还是一笔账。”

她把盒子放回柜子，锁上，钥匙转到底。

“这个格子，七月九号归完，我没再开过。”苏晚说。

“今天开的时候，锁是好的。”

“锁是好的。”她说，“标签右上角翘了。”

林尘看那块小牌。牌是纸的，压在塑料套里。右上角翘起来两毫米。

“标签是我贴的。”苏晚说，“四个角都压平了。”

她把手从柜门上拿开，往门口走。走了两步，停下，回头看了一眼那块牌子，没有回去。

四点十分，林尘在走廊上打了一个电话。

“韩律师。”

“林先生。”

“二〇二六年六月那封律师函。”他说，“你们所的卷宗还在吗。”

“哪一封。”

“启元互动那笔，十二万。落款六月九号。”

电话那头有翻页的声音。

“我查一下。”韩律师说，“卷宗号 2026-0611，启元互动，委托人是启元。函是我们出的，落款日期系统里是六月十二。”

“六月十二。”

“六月十二。”韩律师说，“寄出记录是六月十二下午，签收是六月十三。”

“我六月十号就收到了。”

“那我这边查不到。”韩律师说，“卷宗里只有一份函，六月十二。没有六月九号的版本。”

“能不能调原件。”

“能。”韩律师说，“但要走手续。这个案子去年就结了，卷宗归到分所仓库。调阅要委托人书面申请，我们这边审，审完报分所，分所每周三统一去取。”

“多久。”

“十五天。”韩律师说，“最快十五天。”

“还有别的问题。”

“有。”他说，“调出来也只有一份。”韩律师说，“卷宗里那一份就是六月十二。你手里那份，如果落款是六月九，那它不在我们的卷宗里。”

林尘把手机换到另一只手。

“十五天。”他说。

“十五天。”韩律师说，“你要是急，我可以先出一份情况说明，写明我们这边只有六月十二这一版。这份说明三天能出。”

“出。”

“出了以后呢。”

“出了以后放着。”

五点，他把框拿上三楼，挂在办公室墙上。

墙是白的，去年刷的。他先用手掌在墙上按了一下，找一个高度。框挂上去，下沿离地一米五五。他退后两步看，取下来，往左挪了三公分，再挂。

钉子是杭师傅配的，一寸二。他敲了三下，第一下轻，第二下重，第三下补了两下。

墙上原来有一个钉眼，在框的右下角外面，比框低四公分。那个眼是旧的，眼里有灰。

他把框取下来，翻过去看背板。

背板是一层三合板，背面贴着一张标签，标签上两行铅笔字。

第一行：二〇二七年八月一日，托。

第二行：纸龄 2027。

林尘把框翻回来，重新挂上。钉子进了原来的孔，第二下敲得比第一下重。

他退到门口，看那面墙。

框里的律师函，落款六月十二。

他手机里那张照片，落款六月九。

他把手机放回口袋，从抽屉里拿出那张签收单。签收单是二〇二六年六月十日签的，签收人一栏写着“林尘”，两个字是他自己的字。

他把签收单放在桌上，用手掌压平，压了两遍。

“晚三天。”他说。
